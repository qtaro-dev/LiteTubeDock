# LiteTube Dock

LiteTube Dock は、YouTube や登録済みURLを専用の1ウィンドウで開きっぱなしにするための軽量Webプレイヤーです。

通常ブラウザのような多機能さは持たせず、作業BGM、YouTubeライブ、登録済みURLの簡易表示を目的にしています。

## 主な用途

- YouTubeを作業BGM用に1窓だけ常時起動する
- ChromeやFirefoxとは別の専用ウィンドウでYouTubeを開く
- 登録済みURLをボタンで切り替える
- OBS使用中や作業中に、邪魔になりにくい小窓として使う

## 使用技術

- .NET 8
- WPF
- C#
- Microsoft Edge WebView2
- JSON形式の設定ファイル

## 現在の主な機能

### Web表示

- WebView2でYouTubeを表示
- YouTubeトップ、動画ページ、ライブ配信ページなどを表示可能
- 前回開いていたURLの保存と復元に対応
- WebView2の専用ユーザーデータフォルダを使用

### お気に入りボタン

- 最大10件のお気に入りURLを登録可能
- 画面下部のボタンから登録URLへ移動可能
- 有効 / 無効の切り替えに対応
- 設定ファイルから読み込み
- 設定画面から各スロットを削除可能
- 多重起動時は `data/bookmarks.json` の変更を他の起動中インスタンスへ反映

### 基本操作

- アドレスバーへURLを入力して移動
- ホームへ移動
- 戻る
- 進む
- 再読み込み
- アプリ終了
- 常に最前面 ON / OFF
- 現在URLのコピー
- 現在URLと読み込み状態の表示
- 動画ページ以外への遷移確認
- ヘルプとバージョン情報の表示
- お気に入り設定のインポート / エクスポート

アドレスバーは、一時的に任意URLへ移動するための機能です。URLを入力して `Enter`、または `移動` ボタンでWebView2へ遷移します。`http://` / `https://` がない場合は `https://` を自動補完します。`現在URLをコピー` ボタンで、表示中ページのURLをクリップボードへコピーできます。

アドレスバーはWebView2の現在URLへ同期されます。YouTube内で動画、ライブ、チャンネルなどへ移動した場合も、取得できる現在URLをアドレスバーへ反映します。

表示メニューの `アドレスバーを表示` で表示 / 非表示を切り替えられます。表示状態は `settings.json` の `showAddressBar` に保存され、次回起動時に復元されます。フルスクリーン中はアドレスバーを非表示にし、解除後は `showAddressBar` の設定状態へ戻します。

アドレスバーから移動したURLは自動でお気に入りへ登録されません。お気に入り登録とは別の一時遷移用として使います。

### 外部遷移確認

誤クリック防止として、WebView内のクリックなどでYouTube以外のURLへ移動しようとした場合に確認します。通常のページ遷移だけでなく、新規ウィンドウ要求でも外部リンク確認を行います。

確認メッセージ:

```text
動画ページ以外へ移動しようとしています。
遷移してよろしいですか？
```

この機能は広告ブロックではありません。YouTube広告を非表示、削除、スキップする機能ではなく、誤クリックによる外部遷移を確認するための機能です。

基本設定の `動画ページ以外への遷移を確認する` でON/OFFを変更できます。既定値はONです。確認OFF時でも、新規ウィンドウ要求は可能な範囲で同じLiteTube Dock内に遷移させます。アドレスバーからの明示的な移動、Home、Reload、お気に入りボタンからの移動は確認なしで実行します。

### 詳細操作と右クリックメニュー

LiteTube Dock は、視聴・常駐・簡易表示を目的にしたアプリです。WebView標準の右クリックメニューは表示しません。

YouTube側に報告する通報機能、コメントやライブチャットの詳細メニュー、保存、印刷などの一部機能は、本アプリ内では利用できない場合があります。これらの操作が必要な場合は、`現在URLをコピー` でURLをコピーし、通常のブラウザで開いて操作してください。

### ヘルプ

上部メニューの `ヘルプ` から、アプリ内ヘルプとバージョン情報を開けます。

- `ヘルプを開く`: 基本操作、アドレスバー、お気に入りボタン、右クリック登録、自動再生、フルスクリーン、ログイン方針、WebView2ユーザーデータフォルダのリセット方法を確認できます。
- `プレイヤーモード診断`: プレイヤーモードで最後に生成したURL、Referer設定、最後のReferer付与対象URL、付与結果を確認できます。
- `バージョン情報`: アプリ名、バージョン、使用技術、開発者、開発支援、セキュリティ方針を確認できます。

バージョン情報には `開発者: Qtaro`、`開発支援: GPT / CODEX` を表示します。

自動再生はWebView2 / YouTube側の仕様に依存し、必ず再生されるとは限りません。この注意点はアプリ内ヘルプにも記載しています。

### お気に入り設定のインポート / エクスポート

ファイルメニューから、お気に入り設定をJSONファイルとしてインポート / エクスポートできます。

- `お気に入り設定をエクスポート`: 現在の `data/bookmarks.json` を選択したJSONファイルへ保存します。
- `お気に入り設定をインポート`: 選択したJSONを検証し、現在のお気に入り設定を上書きします。

インポート前には確認メッセージを表示し、現在の `bookmarks.json` を設定フォルダへ `bookmarks_backup_yyyyMMdd_HHmmss.json` としてバックアップします。バックアップに失敗した場合はインポートしません。

エクスポート先の既定フォルダは `settings` です。基本設定の `設定フォルダ` から保存先フォルダを指定できます。指定フォルダは `settings.json` の `settingsExportFolder` に保存されます。

インポート / エクスポート対象はお気に入り設定のみです。`settings.json`、WebView2ユーザーデータ、YouTubeログイン状態、Cookie/session、Google ID、パスワード、認証トークンは対象外です。

### 多重起動時のお気に入り同期

LiteTube Dock は複数起動できます。起動中の別インスタンスで `data/bookmarks.json` が保存、削除、インポートにより更新された場合、他のインスタンスのMainWindow上のお気に入りボタン表示も自動で再読み込みします。この再読み込みで現在表示中のWebViewページは移動しません。

同期対象はお気に入り設定のみです。`settings.json`、ウィンドウ位置、ウィンドウサイズ、現在URL、WebView2ユーザーデータ、YouTubeログイン状態、Cookie/sessionは同期しません。

設定画面を開いて編集中に外部変更を検知した場合は、再読み込み確認を表示します。`いいえ` を選ぶと編集中内容を維持しますが、そのまま保存すると外部変更を上書きする可能性があります。複数インスタンスで同時に保存した場合は、最後に保存した内容が優先される可能性があります。

### 設定画面

設定画面では、以下を編集できます。

- ホームURL
- 前回URLを復元するか
- 常に最前面で起動するか
- ウィンドウ位置とサイズを復元するか
- 自動再生を試みるか
- 動画ページ以外への遷移を確認するか
- プレイヤーモードReferer付与を試みるか
- プレイヤーモードReferer値
- お気に入りボタン01〜10の表示名
- お気に入りボタン01〜10のURL
- お気に入りボタン01〜10のアイコン画像パス
- お気に入りボタン01〜10の有効 / 無効
- お気に入りボタン01〜10の再生モード
- お気に入りボタン01〜10の自動再生 / ミュート / ループ
- お気に入りボタン01〜10の削除
- ウィンドウ幅
- ウィンドウ高さ

設定画面の中身はカテゴリごとのUserControlに分割されています。基本設定は `Views/GeneralSettingsView.xaml`、お気に入りボタン設定は `Views/FavoriteButtonsSettingsView.xaml` で個別に管理します。

## 起動方法

Visual Studio から WPF プロジェクトをビルドして実行します。

コマンドラインから実行する場合は、プロジェクトフォルダで以下を実行します。

```powershell
dotnet build
dotnet run
```

起動引数を指定する場合は、ビルド後の実行ファイルに渡します。

```powershell
LiteTubeDock.exe --player-mode
LiteTubeDock.exe --url "https://www.youtube.com/"
LiteTubeDock.exe --player-mode --url "https://www.youtube.com/"
```

`--player-mode` は、LiteTube Dock Control などから複数起動する用途を想定した表示領域優先モードです。メニュー、アドレスバー、お気に入りボタン、ステータスバーを隠して、指定URLまたは既定URLを表示します。`--url` で渡したURLは一時的な表示対象として扱い、お気に入り設定へ自動登録しません。

## 設定ファイル

開発中は、プロジェクトフォルダ内の `data` フォルダに設定ファイルを保存します。

```text
data/settings.json
data/bookmarks.json
```

これらのファイルが存在しない場合は、アプリ起動時に既定内容で自動作成されます。

## settings.json

`settings.json` には、アプリ全体の設定を保存します。

主な内容は以下です。

- ホームURL
- 最後に開いていたURL
- 前回URLを復元するか
- 常に最前面で起動するか
- ショートカットキーを有効にするか
- WebView2ユーザーデータフォルダのパス
- 自動再生を試みるか
- 動画ページ以外への遷移を確認するか
- プレイヤーモードReferer付与を試みるか
- プレイヤーモードReferer値
- ウィンドウサイズプリセット
- ウィンドウ位置
- ウィンドウサイズ

## bookmarks.json

`bookmarks.json` には、最大10件のお気に入りボタン情報を保存します。

各項目には以下を保存します。

- 表示名
- URL
- アイコン画像パス
- 表示順
- 有効 / 無効
- 背景色
- 文字色
- アイコン形状
- アイコン角丸
- 再生モード
- 自動再生
- ミュート
- ループ

背景色と文字色は設定画面の色見本ボタンから選択できます。

内部的には `#RRGGBB` 形式で保存されます。直接 `bookmarks.json` を編集する場合も `#RRGGBB` 形式で指定してください。

例:

```json
{
  "label": "Home",
  "url": "https://www.youtube.com/",
  "sortOrder": 1,
  "isEnabled": true,
  "iconPath": "data/icons/home.png",
  "iconShape": "Square",
  "iconRounded": true,
  "playbackMode": "Normal",
  "autoplay": false,
  "mute": false,
  "loop": false,
  "resumePlayback": true,
  "backgroundColor": "#F0F0F0",
  "foregroundColor": "#000000"
}
```

アイコン画像は `data/icons` に配置できます。対応形式は `.png`, `.jpg`, `.jpeg`, `.webp` です。設定画面のアイコン欄の `選択` ボタンから画像を指定できます。

アイコン未指定時はアイコンを表示しません。画像ファイルが存在しない場合や読み込めない場合も、従来どおりテキストのみのボタンとして表示されます。

`iconShape` は `Square` または `Rectangle` を指定できます。設定画面では `Square` を `四角`、`Rectangle` を `横長` と表示します。`iconRounded` を `true` にすると角丸表示、`false` にすると角丸なしで表示します。アイコンは補助表示であり、お気に入りボタンでは表示名を優先して表示します。

MainWindow下部のお気に入りボタンを右クリックすると、表示中のYouTubeページをその枠へ登録できます。既存登録がある場合は上書き確認を表示します。登録時は現在WebView2で表示中のURLを保存し、表示名には現在ページタイトルの先頭20文字を仮登録します。背景色、文字色、アイコン、形状、角丸設定は維持されます。

設定画面のお気に入りボタン設定では、各スロットの `削除` ボタンで対象スロットだけを初期値へ戻せます。削除は番号を詰める処理ではなく、表示名を `URL1` などの既定名、URLを `https://www.youtube.com/`、有効をOFF、色、アイコン、再生設定を既定値へ戻すスロット初期化です。保存するまでは `data/bookmarks.json` へ反映されません。キャンセルすると削除前の内容に戻ります。

### お気に入りごとの再生オプション

お気に入りごとに `再生モード` を設定できます。

- `通常`: 安定重視です。登録URLをそのまま開き、YouTube通常ページ、コメント欄、関連UIはYouTube側の表示に従います。
- `プレイヤー`: 実験的機能です。YouTube動画URLを可能な範囲で embed URL に変換し、動画プレイヤー中心の表示を試みます。

プレイヤーモードはYouTube embedを使用するため、YouTube側の仕様や動画ごとの埋め込み条件に依存します。一部動画では `Error 153` / `Error 152` などで表示できない場合があります。その場合は再生モードを `通常` に戻してください。LiteTube Dock は Error 153 / Error 152 対策として YouTube embed 関連リクエストへ Referer 付与を試みますが、完全な回避は保証しません。

基本設定では、プレイヤーモード用の `プレイヤーモードReferer付与` ON/OFF と `プレイヤーモードReferer` 値を変更できます。既定値は `https://litetubedock.local/` です。この値は LiteTube Dock のアプリ識別用Refererとして使用します。通常は変更不要です。設定画面で変更して保存すると、アプリ再起動なしで次回のプレイヤーモード遷移から反映されます。Referer値を変更しても再生を保証するものではありません。ヘルプメニューの `プレイヤーモード診断` では、最後に生成したプレイヤーURL、現在のReferer値、設定反映状態、最後にReferer付与を試みたURL、付与結果、付与回数を確認できます。

プレイヤーモードでは、以下のURLを動画ID付きの embed URL へ変換します。

```text
https://www.youtube.com/watch?v=VIDEO_ID
https://youtube.com/watch?v=VIDEO_ID
https://youtu.be/VIDEO_ID
```

お気に入りごとに `自動再生`、`ミュート`、`ループ` も設定できます。プレイヤーモードでは、embed URLへ `autoplay=1`、`mute=1`、`loop=1` を付与します。単体動画のループでは、YouTube仕様に合わせて `playlist=VIDEO_ID` も付与します。

自動再生やループは YouTube / WebView2 側の仕様に依存するため、必ず期待どおり動作するとは限りません。YouTubeページ内の再生ボタン自動クリック、DOM操作、YouTube API連携は行いません。

自動再生、ミュート、ループはプレイヤーモード用の補助設定です。設定画面では、再生モードが `通常` の場合これらの項目は無効になります。チェック状態は保持されるため、プレイヤーモードへ戻すと以前の設定を再利用できます。

再生モードが `通常` の場合、ミュートやループはYouTube標準機能を使用する方針です。チャンネルURL、YouTubeトップ、検索ページ、YouTube以外のURLは無理にembed化せず、登録URLのまま開きます。

お気に入りごとに `リジューム` も設定できます。ONの場合は既存URLの `t=` や `start=`、YouTube側の再生位置復元を許容します。OFFの場合は開始位置系パラメータを除去し、できるだけ最初から再生されるURLに整えます。ただし YouTube / WebView2 側の仕様により、必ず最初から再生されるとは限りません。再生位置をJavaScriptやDOM操作で強制変更する処理は行いません。

画質設定はYouTube側の制御に依存するため、LiteTube Dock側では固定しません。低負荷で使いたい場合は、プレイヤーモード、ミュート、小さいウィンドウサイズを組み合わせてください。

## ウィンドウサイズ

表示メニューの「ウィンドウサイズ」から以下のプリセットを選択できます。

- `800x600`
- `960x540`
- `1280x720`
- `1600x900`
- `1920x1080`
- `540x960`
- `720x1280`
- `900x1600`
- `1080x1920`
- `Custom`

縦長プリセットはYouTubeショートなどの縦長コンテンツ向けに利用できます。

設定画面ではカスタムのウィンドウ幅・高さを保存できます。カスタムサイズは幅 `540` 〜 `3840`、高さ `360` 〜 `2160` の範囲に制限されます。

設定画面の基本設定でも、ウィンドウサイズのドロップダウンから同じプリセットを選択できます。`現在のサイズ` を選ぶと、現在表示中のMainWindowの幅と高さを入力欄へ反映します。`現在のウィンドウサイズを取得` ボタンを押すと、現在のMainWindow幅・高さを明示的に入力欄へ反映できます。`カスタム` を選ぶと、幅と高さを手入力できます。保存後はMainWindowのサイズへ反映され、次回起動時にも復元されます。

設定画面の「ウィンドウ位置・サイズを初期値に戻す」ボタンから、保存済みの位置とサイズを初期値へ戻せます。既定値は `Left=100`、`Top=100`、`Width=800`、`Height=600` です。

表示メニューの「ウィンドウ位置をリセット」は、メインディスプレイ左上付近へウィンドウ位置のみを戻します。設定画面のリセットボタンは位置とサイズの両方を戻します。マルチディスプレイ構成変更などで保存済み位置が画面外になった場合も、起動時に安全な位置へ戻します。

## 自動再生

基本設定の `自動再生` をONにすると、WebView2初期化時に Chromium の自動再生許可オプションを指定し、YouTube動画やライブの自動再生を試みます。

この設定は WebView2 / Chromium / YouTube 側の仕様やポリシーに依存するため、ONでも必ず再生が開始されるとは限りません。YouTubeページ内の再生ボタン自動クリック、DOM操作、YouTube API連携は行いません。

自動再生設定は `settings.json` の `enableAutoplay` に保存されます。WebView2初期化オプションとして使うため、反映にはアプリの再起動が必要です。

ループ再生はYouTube標準のループ機能を使用してください。

## ショートカットキー

ショートカットキーは、`data/settings.json` の `enableShortcutKeys` で有効 / 無効を切り替えます。

### お気に入りボタン

- `F1` 〜 `F10`: お気に入り01〜10を開く

補足: YouTube側にも数字キーのショートカットがあるため、安定して使う場合は `F1` 〜 `F10` の利用を推奨します。

### 基本操作

- `Ctrl + R`: 再読み込み
- `Alt + Left`: 戻る
- `Alt + Right`: 進む
- `Ctrl + H`: ホームへ移動
- `Ctrl + Q`: アプリ終了

## フルスクリーン

- `Alt + Enter`: フルスクリーン切り替え
- `Esc`: フルスクリーン解除

フルスクリーン中は、WebView2表示領域を広く使うため、以下のUIを非表示にします。

- 上部メニュー
- アドレスバー
- お気に入りボタン列
- ステータスバー

フルスクリーン状態そのものは保存しません。  
次回起動時は通常表示で起動します。

## YouTubeログイン・ログアウト方針

LiteTube Dock は、YouTube / Google アカウントのログイン・ログアウト機能を独自に実装しません。

### ログインして使う場合

YouTubeトップ画面を開き、YouTube標準のログイン画面からユーザー自身がログインしてください。

### ログインせずに使う場合

未ログイン状態のまま利用できます。

### ログアウトする場合

YouTube画面上のアカウントメニューから、ユーザー自身がログアウトしてください。

LiteTube Dock側には、独自のログインボタン、ログアウトボタン、自動ログイン機能は実装しません。

## ログイン状態の保持

YouTubeログイン状態は、WebView2のユーザーデータフォルダに保存される標準のCookie / Session管理に任せます。

```text
data/webview2-user-data
```

LiteTube Dock は、以下の情報をアプリ側のJSONファイルへ保存しません。

- GoogleアカウントID
- パスワード
- 認証トークン
- 認証情報
- Cookieの独自保存データ

ログイン状態を完全にリセットしたい場合は、LiteTube Dock を終了したうえで、以下のフォルダを削除してください。

```text
data/webview2-user-data
```

次回起動時にフォルダは自動作成されます。

## 実装しないこと

このアプリでは、以下は実装しません。

- タブ機能
- YouTube広告ブロック
- YouTube広告の非表示、削除、スキップ
- YouTube UI改変
- Googleログインの自動化
- Google ID / パスワード / 認証トークンの保存
- YouTubeコメント自動投稿
- 複数ウィンドウ管理

## 注意事項

- LiteTube Dock は、YouTubeを表示するための専用WebView2ウィンドウです。
- YouTube自体の負荷はWebView2内でも発生します。
- 通常ブラウザよりUI要素を減らすことで、用途を絞った軽量運用を目指しています。
- YouTubeの仕様変更により、表示やログイン挙動が変わる可能性があります。
