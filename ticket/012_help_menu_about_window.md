## 4. ヘルプ本文に記載する内容

ヘルプ本文には以下を記載する。

### LiteTube Dock について

- YouTubeや登録済みURLを専用の1ウィンドウで開く軽量Webプレイヤーであること
- 通常ブラウザの代替ではなく、作業BGM、YouTubeライブ、登録URLの簡易表示を目的にしていること

### 基本操作

- ホーム
- 戻る
- 進む
- 再読み込み
- 常に最前面
- フルスクリーン

### アドレスバー

- URLを入力して `Enter` または `移動` ボタンで遷移できること
- `http://` / `https://` がない場合は `https://` を補完すること
- YouTube内で動画やライブへ移動した場合、現在URLへ同期されること
- 表示メニューからアドレスバーの表示/非表示を切り替えられること

### お気に入りボタン

- 最大10件のお気に入りURLを登録できること
- ボタン押下で登録URLへ移動できること
- 設定画面で表示名、URL、色、アイコン、有効/無効を変更できること

### 右クリック登録

- お気に入りボタンを右クリックすると `現在再生中のムービーを登録` が使えること
- 現在表示中のYouTubeページURLを登録すること
- 表示名はページタイトルの先頭20文字を仮登録すること
- 既存登録がある場合は上書き確認が出ること
- 色やアイコン設定は維持されること

### 自動再生

必ず以下の内容を記載する。

```text
自動再生を使うには、設定画面の「自動再生」をONにして保存し、アプリを再起動してください。

自動再生ONの場合、LiteTube DockはWebView2側で自動再生を試みます。
ただし、YouTube側やWebView2側の仕様により、必ず自動再生されるとは限りません。

お気に入りボタンから動画URLへ移動した場合も、自動再生設定が有効であれば再生開始を試みます。
```

### ループ再生

- ループ再生はLiteTube Dock側では実装しないこと
- ループ再生したい場合はYouTube標準のループ機能を使用すること

### フルスクリーン

- `Alt + Enter` でフルスクリーン切り替え
- `Esc` でフルスクリーン解除
- フルスクリーン中はメニュー、アドレスバー、お気に入りボタン、ステータスバーが非表示になること
- 解除後は設定状態に戻ること

### YouTubeログイン・ログアウト

- LiteTube DockはYouTube / Googleログイン機能を独自実装しないこと
- ログインはYouTube標準画面でユーザーが行うこと
- ログアウトもYouTube画面上から行うこと
- Google ID、パスワード、認証トークンを保存しないこと
- ログイン状態はWebView2標準のCookie / Session管理に任せること

### ログイン状態のリセット

- ログイン状態を完全にリセットしたい場合は、アプリ終了後に以下を削除すること

```text
data/webview2-user-data
```

### ウィンドウサイズ

- 表示メニューまたは設定画面からサイズプリセットを選べること
- 横長プリセットと縦長プリセットがあること
- YouTubeショート向けに縦長サイズを選べること
- `現在のウィンドウサイズを取得` ボタンで現在サイズを取得できること
- `ウィンドウ位置・サイズを初期値に戻す` で既定値へ戻せること

## 8. メニュー操作

`OpenHelpMenuItem` をクリックしたら `HelpWindow` を開く。

`AboutMenuItem` をクリックしたら `AboutWindow` を開く。

仕様:

- 親ウィンドウをOwnerに設定してよい
- モーダル表示でも非モーダル表示でもよい
- まずは `ShowDialog()` でよい
- 同時に複数開いても大きな問題がなければよいが、可能なら多重起動は避ける
