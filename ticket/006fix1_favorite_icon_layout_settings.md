# タスク名

チケット006fix1 お気に入りボタンのアイコン表示仕様と設定画面レイアウト改善

# 目的

チケット006で追加予定、または追加済みの `IconPath` を使ったお気に入りボタン画像アイコン機能について、実用しやすい表示仕様と設定画面UIへ改善する。

現在の設定画面は、お気に入りボタン1件が横1行にまとまっており、表示名、URL、アイコン、背景色、文字色、有効状態が横に詰まりやすい。

特に、YouTubeのお気に入り名やURLが見づらくなると本末転倒なので、以下を実現する。

- アイコンは補助要素として扱う
- アイコン未指定時はアイコンを表示しない
- お気に入り名とURLの見やすさを優先する
- アイコン表示形状を四角形または長方形から選べるようにする
- アイコンの角丸オプションを設定できるようにする
- お気に入りボタンの横幅に応じて、アイコンや文字が自然に収まるようにする
- 設定画面を1件2段程度の見やすいレイアウトへ改善する

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- 既存のMainWindow、SettingsWindowのレイアウトを全面的に作り直さないこと。

## 2. アイコン表示の基本方針

お気に入りボタンのアイコンは、あくまで補助表示とする。

仕様:

- `IconPath` が空、null、未指定の場合はアイコンを表示しない
- `IconPath` が指定され、画像ファイルが存在する場合のみアイコンを表示する
- 画像ファイルが存在しない場合は、クラッシュせずテキスト表示のみへフォールバックする
- お気に入りボタンの表示名は必ず見えるようにする
- アイコン表示によって表示名が極端に読みにくくならないようにする

## 3. アイコン形状設定を追加する

お気に入りボタンのアイコン表示形状を設定できるようにする。

選択肢:

- `Square`
  - 四角形
- `Rectangle`
  - 長方形

推奨JSON項目:

```json
{
  "iconShape": "Square"
}
```

既定値:

```text
Square
```

## 4. 角丸オプションを追加する

アイコンの角丸有無、または角丸値を設定できるようにする。

簡易実装の場合:

```json
{
  "iconRounded": true
}
```

より柔軟にする場合:

```json
{
  "iconCornerRadius": 8
}
```

推奨:

- `IconRounded` または `IconCornerRadius` のどちらか一方でよい
- 初期実装は `IconRounded: true/false` でも可
- 角丸ONの場合は `CornerRadius=8` 程度
- 角丸OFFの場合は `CornerRadius=0`

既定値:

```text
IconRounded = true
```

## 5. アイコンサイズの考え方

お気に入りボタンは横方向に複数並ぶため、アイコンサイズは固定巨大サイズにしないこと。

基本方針:

- お気に入りボタンの実際の横幅に対して自然に収まるサイズにする
- アイコン数とボタン列の横幅で均等割りされることを前提に、過剰に大きいアイコンを避ける
- 1ボタン内で、アイコンと表示名がどちらも見えるようにする

推奨サイズ例:

- Square: `24x24` 〜 `32x32`
- Rectangle: `48x24` 〜 `64x32`

ただし、ウィンドウ幅が狭い場合は自動的に縮小、またはテキスト優先表示にすること。

## 6. MainWindowのお気に入りボタン表示

お気に入りボタン表示は以下の優先順位にする。

1. 表示名
2. 背景色・文字色
3. アイコン

仕様:

- アイコン未指定なら、従来どおりテキスト中心のボタン表示
- アイコン指定ありなら、アイコン + 表示名を表示
- 画像読み込み失敗時は、テキストのみ表示
- ボタン押下でURL遷移する既存機能は維持
- 背景色・文字色設定は維持
- 無効ボタンは既存の無効表示を維持

表示例:

```text
[ icon ] Home
```

または

```text
[ icon ]
Home
```

どちらの配置でもよいが、表示名が読みにくくならない方を選ぶこと。

## 7. SettingsWindowのレイアウト改善

現在の横1行レイアウトでは項目が詰まりやすいため、お気に入りボタン設定を1件2段程度のレイアウトへ改善する。

推奨表示:

```text
01  表示名 [ Home________________ ]   有効 [✓]
    URL    [ https://www.youtube.com/..._____________________ ]
    アイコン [ data/icons/home.png____________ ] [選択]
    背景色 [#FF0000] [■]   文字色 [#FFFFFF] [■]
    アイコン形状 [Square ▼]   角丸 [✓]
```

方針:

- 表示名の入力欄は現状より広くする
- URL入力欄はできるだけ広くする
- アイコンパス欄も現状より分かりやすくする
- 背景色・文字色のカラーピッカー機能は維持する
- 有効チェックボックスは各行で分かりやすく配置する
- 横幅が足りない場合は縦方向に伸びてもよい
- `ScrollViewer` で縦スクロールできるようにする

## 8. アイコン選択ボタンを追加する

アイコンパス欄の横にファイル選択ボタンを追加する。

推奨 `x:Name`:

- `FavoriteIconSelectButton01` 〜 `FavoriteIconSelectButton10`

仕様:

- ボタン表示名は `選択`
- 押下すると画像ファイル選択ダイアログを開く
- 選択したファイルのパスを `FavoriteIconPathTextBoxXX` に反映する
- 可能であれば、`data/icons` 配下への相対パスを優先する
- 難しい場合は、まず絶対パス入力でもよい
- 存在しない画像パスでもクラッシュしない

対応画像形式:

- `.png`
- `.jpg`
- `.jpeg`
- `.webp`

## 9. data/icons フォルダ

アイコン画像置き場として、以下のフォルダを使用する。

```text
data/icons
```

仕様:

- 存在しない場合は自動作成してよい
- READMEに推奨配置先として記載する
- デフォルト画像を必ず同梱する必要はない
- 無指定時はアイコン非表示にするため、デフォルト画像は必須ではない

## 10. デフォルトPNGについて

将来的に以下のようなデフォルトPNGを置けるようにする。

例:

```text
data/icons/home.png
data/icons/music.png
data/icons/live.png
data/icons/game.png
data/icons/news.png
data/icons/work.png
```

ただし、今回のタスクではデフォルトPNGの作成・同梱は必須ではない。

重要:

- アイコンはユーザーが任意で指定する
- 無指定なら表示しない
- YouTubeのお気に入り名が見づらくなる実装は避ける

## 11. JSON項目

`bookmarks.json` に以下の項目を追加・保存できるようにする。

推奨:

```json
{
  "label": "Home",
  "url": "https://www.youtube.com/",
  "sortOrder": 1,
  "isEnabled": true,
  "backgroundColor": "#F0F0F0",
  "foregroundColor": "#000000",
  "iconPath": "",
  "iconShape": "Square",
  "iconRounded": true
}
```

既存の `iconPath` がある場合は維持すること。

不明な値や不正な値は既定値へフォールバックすること。

## 12. README更新

READMEに以下を追記する。

- お気に入りボタンにアイコンを設定できること
- アイコン未指定時はアイコンを表示しないこと

- 対応画像形式

- 角丸オプションがあること
