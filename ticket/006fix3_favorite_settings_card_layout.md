# タスク名

チケット006fix3 お気に入り設定画面をカード型レイアウトへ改善

# 目的

チケット006fix2で、お気に入り設定画面に区切り線と余白を追加したが、現在のGridベースの横長表形式では、区切り線が入力欄に近すぎたり、項目同士が重なって見えたりしている。

このまま区切り線だけを調整しても、解像度・DPI・フォントサイズ・ウィンドウ幅によって再び崩れる可能性が高い。

そのため、お気に入り設定画面を「横長の表形式」から「1件ごとのカード形式」に変更し、各お気に入り番号ごとのまとまりを明確にする。

# 対象ファイル（推定可）

- `SettingsWindow.xaml.cs`
- `README.md`

必要に応じて、SettingsWindow用のStyle、Resource、補助メソッドを追加してよい。

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。

- SettingsWindow全体を全面再設計せず、`お気に入りボタン` 設定部分のレイアウト改善を中心に行うこと。

## 2. 現状の問題

現在のお気に入り設定画面は、1件2段構成になっているが、以下の問題がある。

- 横区切り線が入力欄に近すぎる
- 区切り線がUIに重なって見える
- 各番号の設定範囲がまだ分かりにくい
- 入力欄・ボタン・チェックボックスが横方向に詰まっている
- 表形式のGridに後付けで線を入れているため、調整が難しい

## 3. カード型レイアウトへ変更する

お気に入り設定を、1件ごとに `Border` で囲んだカード型レイアウトに変更する。

イメージ:

```text
┌───────────────────────────────────────────────┐
│ 01  表示名 [ Home________________ ]   有効 [✓] │
│     URL    [ https://www.youtube.com/...____ ] │
│     アイコン [ data/icons/home.png_____ ] [選択] │
│     背景色 [#FF0000] [■]  文字色 [#FFFFFF] [■] │
│     形状 [Square ▼]  角丸 [✓]                 │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ 02  表示名 [ URL2________________ ]  有効 [ ]  │
│     URL    [ https://www.youtube.com/...____ ] │
│     アイコン [______________________] [選択]   │
│     背景色 [#F0F0F0] [■]  文字色 [#000000] [■] │
│     形状 [Square ▼]  角丸 [✓]                 │
└───────────────────────────────────────────────┘
```

## 4. カードの基本仕様

各カードは以下の見た目にする。

- `Border` で囲む
- `BorderBrush` は薄いグレー
- `BorderThickness` は `1`
- `CornerRadius` は `4`〜`8` 程度
- `Padding` は `8`〜`12` 程度
- `Margin` は上下に `6`〜`10` 程度
- カード同士の間隔を十分に空ける
- 既存の黄色い区切り線のような重なる横線は使用しない

推奨:

```text
BorderBrush = #D0D0D0
BorderThickness = 1
CornerRadius = 6
Padding = 10
Margin = 0,0,0,10
```

## 5. 1カード内の配置

1つのお気に入りカード内では、以下の構成を推奨する。

### 1段目

- No
- 表示名
- 表示名入力欄
- 有効チェックボックス

### 2段目

- URL
- URL入力欄

### 3段目

- アイコン
- アイコンパス入力欄
- 選択ボタン

### 4段目

- 背景色
- 背景色コード入力欄
- 背景色見本ボタン
- 文字色
- 文字色コード入力欄
- 文字色見本ボタン

### 5段目

- 形状
- 形状ドロップダウン
- 角丸チェックボックス

## 6. No表示を分かりやすくする

`01` 〜 `10` の番号はカード左上、またはカード先頭に見出しとして表示する。

仕様:

- 番号は太字にする
- 番号と表示名が近くに見えるようにする
- 番号がカード全体の見出しだと分かる配置にする

例:

```text
01  表示名 [Home]  有効 [✓]
```

## 7. 入力欄の視認性を改善する

カード型にすることで、以下の入力欄を見やすくする。

- 表示名入力欄
- URL入力欄
- アイコンパス入力欄

特にURL欄とアイコンパス欄は横幅を広く取ること。

推奨:

- URL入力欄は可能な範囲で横に広くする
- アイコンパス欄も選択ボタンの左側で広く取る
- 表示名は長めの名前でも見やすい幅を確保する

## 8. 既存x:Nameの維持

以下の既存要素名は可能な限り維持すること。

- `FavoriteLabelTextBox01` 〜 `FavoriteLabelTextBox10`
- `FavoriteUrlTextBox01` 〜 `FavoriteUrlTextBox10`
- `FavoriteIconPathTextBox01` 〜 `FavoriteIconPathTextBox10`

- `FavoriteForegroundColorTextBox01` 〜 `FavoriteForegroundColorTextBox10`
- `FavoriteBackgroundColorButton01` 〜 `FavoriteBackgroundColorButton10`
- `FavoriteForegroundColorButton01` 〜 `FavoriteForegroundColorButton10`

名前変更が必要な場合は、既存の `SettingsWindow.xaml.cs` 側の参照も必ず追従すること。

## 9. ScrollViewerは維持する

カード型にすると縦方向に長くなるため、`ScrollViewer` による縦スクロールを維持する。

仕様:

- 10件すべてが1画面に収まらなくてもよい
- 縦スクロールで確認できればよい
- 横スクロールはできるだけ発生させない
- 横方向の詰め込みより、縦方向に伸ばして見やすさを優先する

## 10. 色設定・アイコン設定機能を壊さない

カード型レイアウトへ変更しても、以下の機能は維持すること。

- 背景色の色見本ボタンを押すとカラー選択ウィンドウが開く
- 文字色の色見本ボタンを押すとカラー選択ウィンドウが開く
- 色選択後、色コード欄と色見本ボタンが更新される
- アイコン選択ボタンを押すと画像選択ダイアログが開く
- 画像選択後、アイコンパス欄へ反映される
- 形状を `Square` / `Rectangle` から選択できる
- 角丸ON/OFFを設定できる
- 有効ON/OFFを設定できる
- 保存できる
- キャンセルできる
- 初期値に戻せる
