# タスク名

チケット010 現在再生中のYouTube動画をお気に入りボタンへ登録

# 目的

現在の LiteTube Dock では、お気に入りボタンへURLを登録するには設定画面を開いて、表示名やURLを手入力する必要がある。

YouTube動画やYouTubeライブを視聴中に「この動画を後でまた開きたい」と思った場合、設定画面を開かずに、現在表示中・再生中のYouTubeページをお気に入りボタンへすぐ登録できるようにする。

具体的には、お気に入りボタンを右クリックした時にコンテキストメニューを表示し、現在表示中のURLとYouTubeページタイトルをそのお気に入り枠へ登録できるようにする。

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- 既存のWebView2表示、アドレスバー、お気に入りボタン、設定画面、ステータスバーを壊さないこと。

## 2. お気に入りボタン右クリックメニューを追加する

MainWindow下部のお気に入りボタン01〜10に、右クリック用のコンテキストメニューを追加する。

メニュー項目:

```text
現在再生中のムービーを登録
```

推奨 `x:Name`:

- `RegisterCurrentMovieMenuItem01` 〜 `RegisterCurrentMovieMenuItem10`

既存のお気に入りボタン名:

- `FavoriteButton01` 〜 `FavoriteButton10`

は維持すること。

## 3. 右クリック登録の対象

右クリックしたお気に入りボタンの番号に対して、現在表示中のWebView2 URLを登録する。

例:

```text
FavoriteButton03 を右クリック
↓
現在再生中のムービーを登録
↓
bookmarks.json の sortOrder 3 または3番目のお気に入りへ登録
```

既存のBookmarkServiceの管理順序と整合させること。

## 4. 登録するURL

登録するURLは、現在WebView2で表示中のURLを使用する。

優先取得元:

- `CoreWebView2.Source`
- 既存の現在URL取得ヘルパー
- `PlayerWebView.Source`

既にチケット008fix1で現在URL取得処理が共通化されている場合は、その処理を利用すること。

仕様:

- YouTube動画ページなら動画URLを登録する
- YouTubeライブページならライブURLを登録する
- YouTubeトップページやチャンネルページでも、現在表示中URLとして登録してよい
- URLが空、null、不正な場合は登録せず、ステータスバーにエラー表示すること

## 5. 登録する表示名

表示名は、現在表示中のYouTubeページタイトルを仮表示名として登録する。

取得方法:

- `CoreWebView2.DocumentTitle`
- または JavaScript で `document.title` を取得
- 既存処理と安全に整合する方法を選ぶこと

表示名ルール:

- 取得したタイトルの先頭20文字を使用する
- 前後の空白は削除する
- タイトルが空、null、取得失敗の場合は既定名を使用する

既定名例:

```text
YouTube
```

または

```text
Movie
```

タイトルが以下のような形式の場合でも、まずは先頭20文字でよい。

```text
動画タイトル - YouTube
```

今回のタスクでは、` - YouTube` の除去は必須ではない。  
ただし、簡単に安全に除去できる場合は行ってもよい。

## 6. 表示名20文字制限

表示名は先頭20文字に切り詰める。

仕様:

- 20文字を超える場合は先頭20文字
- 20文字以下の場合はそのまま
- 空白だけの場合は既定名
- 切り詰め時にアプリがクラッシュしないこと

例:

```text
元タイトル: とても長いYouTube動画タイトルサンプルです
登録名: とても長いYouTube動画タイトル
```

## 7. 既存登録がある場合の確認

右クリックしたお気に入り枠に既に有効な登録がある場合、上書き確認ダイアログを表示する。

確認メッセージ:

```text
すでに登録があります。登録してよろしいですか？
```

仕様:

- `はい` または `OK` を選択した場合のみ上書き登録する
- `いいえ` または `キャンセル` を選択した場合は登録しない
- 既存登録が無効、URL空、未登録扱いの場合は確認なしで登録してよい

判定基準は既存データ構造に合わせてよい。

推奨判定:

- `IsEnabled == true` かつ `Url` が空ではない場合は登録あり
- または `Url` が空ではない場合は登録あり

既存挙動と矛盾しない方式を選ぶこと。

## 8. 登録時のBookmarkItem更新

登録時には、対象の `BookmarkItem` を以下のように更新する。

- `Label`
  - 現在ページタイトルの先頭20文字
- `Url`
  - 現在URL
- `IsEnabled`
  - `true`
- `SortOrder`
  - 既存の番号を維持
- `BackgroundColor`
  - 既存値を維持
- `ForegroundColor`
  - 既存値を維持
- `IconPath`
  - 既存値を維持
- `IconShape`
  - 既存値を維持
- `IconRounded`
  - 既存値を維持

重要:

- 登録時に色やアイコン設定を勝手に初期化しないこと
- その枠の見た目設定は維持し、表示名とURLと有効状態を更新すること

## 9. 登録後の反映

登録完了後、以下を行う。

- `bookmarks.json` に保存する
- MainWindowのお気に入りボタン表示を更新する
- 対象ボタンの表示名が新しいタイトルになる
- 対象ボタンをクリックすると登録したURLへ遷移する
- ステータスバーに登録完了メッセージを表示してよい

メッセージ例:

```text
現在のムービーをお気に入り03へ登録しました
```

## 10. 設定画面との整合性

右クリック登録後、設定画面を開いた場合、登録した内容が表示されること。

確認対象:

- 表示名
- URL
- 有効状態

設定画面側の保存・キャンセル処理を壊さないこと。

## 11. URL・タイトル取得失敗時の動作

以下の場合は登録しない。

- 現在URLが取得できない
- URLが空
- URLが明らかに不正
- WebView2が未初期化

ステータスバーに分かるメッセージを表示すること。

例:

```text
現在URLを取得できませんでした
```

タイトル取得だけ失敗した場合は、既定名で登録してよい。

## 12. 右クリックメニューと通常クリックの違い

- 左クリック
  - 既存どおりお気に入りURLへ遷移する

- 右クリック
  - コンテキストメニューを表示する

左クリックの既存挙動を壊さないこと。

## 13. README更新

READMEに以下を追記する。

- お気に入りボタンを右クリックすると、現在表示中のYouTubeページを登録できること
- 既存登録がある場合は確認メッセージを表示すること
- 表示名は現在ページタイトルの先頭20文字を仮登録すること
- URLは現在WebView2で表示中のURLを使用すること
- 色やアイコン設定は維持されること

## 14. 実装しないこと

今回のタスクでは以下を実装しない。

- YouTube API連携
- YouTube動画タイトルのAPI取得
- サムネイル取得
- アイコン自動設定
- 再生リスト登録
- お気に入り並び替え
- お気に入り件数増加
- 現在URLを自動的に空き枠へ登録する処理
- Googleログイン自動化
- YouTube UI改変
