# タスク名

チケット016 お気に入り設定の削除ボタン追加

# 目的

現在のお気に入り設定画面では、登録済みのお気に入りを解除したい場合、表示名・URL・アイコンなどを手入力で消す必要がある。

これでは操作が分かりにくく、誤操作もしやすい。

そのため、お気に入り設定画面の各お気に入りカードに `削除` ボタンを追加し、対象スロットを安全に初期化できるようにする。

ここでの削除は、配列要素を詰める削除ではなく、スロット番号を維持したまま内容を初期値へ戻す「スロット初期化」とする。

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- MainWindow、SettingsWindow、既存UserControl構成を壊さないこと。
- 既存のお気に入り保存・読み込み・右クリック登録・インポート/エクスポート処理を壊さないこと。

## 2. お気に入りカードに削除ボタンを追加する

`Views/FavoriteButtonsSettingsView.xaml` の各お気に入りカード内に `削除` ボタンを追加する。

推奨表示名:

```text
削除
```

推奨 `x:Name`:

```text
FavoriteDeleteButton01
FavoriteDeleteButton02
...
FavoriteDeleteButton10
```

配置場所:

- 各カード右上
- または `有効` チェックボックス付近
- 既存入力欄を圧迫しすぎない場所

既存の表示名、URL、アイコン、背景色、文字色、形状、角丸、再生モード、自動再生、ミュート、ループ、リジューム、有効チェックを壊さないこと。

## 3. 削除確認ダイアログを表示する

削除ボタンを押したら、確認ダイアログを表示する。

文言例:

```text
このお気に入りを削除しますか？
```

補足表示してよい文言:

```text
表示名、URL、アイコン、色、再生設定を初期値に戻します。
```

ボタン:

```text
はい / いいえ
```

推奨:

- `いいえ` をデフォルト選択にする
- 誤操作防止のため、Enterだけで削除されにくい状態にする

## 4. 削除時はスロット初期化する

削除は配列から要素を消すのではなく、対象番号のスロット内容を初期値へ戻す。

例:

```text
02を削除
↓
02番スロットは残す
↓
表示名: URL2
URL: https://www.youtube.com/
有効: false
その他: 既定値
```

推奨初期値:

- `Label`: `URL2` など既存初期値ルールに合わせる
- `Url`: `https://www.youtube.com/`
- `IsEnabled`: `false`
- `BackgroundColor`: 既定背景色
- `ForegroundColor`: 既定文字色
- `IconPath`: 空
- `IconShape`: `Square`
- `IconRounded`: `true`
- `PlaybackMode`: `Normal`
- `Autoplay`: `false`
- `Mute`: `false`
- `Loop`: `false`
- `ResumePlayback`: `true`

ただし、既存の既定値定義がある場合はそれを最優先で使うこと。

## 5. 初期化後は設定画面へ即時反映する

削除確認で `はい` を選んだ場合、対象カードの各入力欄を即時に初期値へ戻す。

反映対象:

- 表示名
- URL
- アイコン
- 背景色
- 文字色
- 形状
- 角丸
- 再生モード
- 自動再生
- ミュート
- ループ
- リジューム
- 有効

保存ボタンを押すまでは、実ファイルへ保存しない方針でよい。

## 6. キャンセル時の挙動

確認ダイアログで `いいえ` を選んだ場合は、何も変更しない。

## 7. 保存処理との整合性

削除後、設定画面の `保存` を押すと `data/bookmarks.json` に初期化結果が保存される。

`キャンセル` を押した場合は、削除操作も保存されないこと。

## 8. 初期値に戻すボタンとの違いを維持する

既存の `初期値に戻す` は全体設定を初期化する操作として維持する。

今回追加する `削除` は、対象のお気に入りスロット1件だけを初期化する操作とする。

## 9. MainWindowのボタン表示への反映

保存後、MainWindowのお気に入りボタン表示が更新されること。

削除されたスロットは、既存の無効スロット表示に従う。

例:

```text
-
```

または既存無効表示ルール。

## 10. インポート/エクスポートとの整合性

削除後にエクスポートした場合、初期化された内容がJSONへ出力されること。

インポート後も削除ボタンは正常に動作すること。

## 11. README更新

READMEに以下を追記する。

- お気に入り設定画面から各スロットを削除できること
- 削除はスロット番号を詰めず、その番号の内容を初期値へ戻すこと
- 保存するまで実ファイルには反映されないこと
- キャンセルすれば削除前に戻ること

## 12. ヘルプ更新

`Constants/HelpContent.cs` にも同等の説明を追記する。

## 13. 実装しないこと

今回のタスクでは以下を実装しない。

- お気に入り件数の増加
- スロット番号の詰め直し
- ドラッグ＆ドロップ並び替え
- 複数選択削除
- 削除済み履歴
- ゴミ箱/復元機能
- インポート/エクスポート形式の変更
- YouTubeログイン情報の操作
- WebView2ユーザーデータの削除
