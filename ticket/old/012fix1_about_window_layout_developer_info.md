- ユーザーはコードを直接編集しない前提である
- 実装・修正はすべて CODEX が行う
- 既存設計を破壊しない
- 既存テーマ・ライブラリ構成を維持する
- ハードコード文字列は禁止
- ICommand構造を崩さない
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと
- `MainWindow.xaml`、`SettingsWindow.xaml`、既存 `Views/*.xaml` と既存 `x:Name` は原則維持すること
- UIを大きく作り直さず、既存UIに処理を接続する形を優先すること
- YouTube / Google のログイン・ログアウト機能をアプリ側で独自実装しないこと
- Google ID、パスワード、認証トークンを保存しないこと

# タスク名

チケット012fix1 バージョン情報ウィンドウの表示崩れ修正と開発者情報追加

# 目的

チケット012で追加した `バージョン情報` ウィンドウにおいて、セキュリティ方針の本文が右端で切れて表示されている。

現在の表示では、以下の文言が1行に収まりきらず、末尾が見切れている。

```text
Google ID、パスワード、認証トークンは保存しません。
```

バージョン情報ウィンドウはユーザーがアプリの情報を確認するための画面なので、本文が切れずに読めるように修正する。

あわせて、開発者情報として以下を表示する。

```text
開発者: Qtaro
開発支援: GPT / CODEX
```

# 対象ファイル（推定可）

- `AboutWindow.xaml`
- `AboutWindow.xaml.cs`
- `Constants/AppConstants.cs`
- `README.md`

必要に応じて、バージョン情報表示用の定数を追加してよい。

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- MainWindow、SettingsWindow、HelpWindow、既存機能を壊さないこと。

## 2. セキュリティ方針の表示崩れを修正する

`AboutWindow.xaml` のセキュリティ方針本文が右端で切れないように修正する。

対応例:

- 対象 `TextBlock` に `TextWrapping="Wrap"` を設定する
- 横幅固定で見切れている場合は、親要素のレイアウトを見直す
- 必要に応じて、本文を2行に分割する
- `HorizontalAlignment="Stretch"` など、ウィンドウ幅に合わせて表示できる構成にする

推奨表示:

```text
Google ID、パスワード、認証トークンは保存しません。
YouTubeログイン状態はWebView2標準のCookie/session管理に任せます。
```

上記2行が切れずに表示されること。

## 3. AboutWindowのサイズを見直す

必要に応じて、`AboutWindow` の初期サイズを少し広げる。

推奨例:

```text
Width: 480
Height: 420
```

ただし、既存デザインを大きく崩さないこと。

## 4. 開発者情報を追加する

バージョン情報ウィンドウに、開発者情報を追加する。

表示項目:

```text
開発者
Qtaro

開発支援
GPT / CODEX
```

または、以下のように1行表示でもよい。

```text
開発者: Qtaro
開発支援: GPT / CODEX
```

表示位置:

- 使用技術の下
- セキュリティ方針の上

推奨順:

```text
LiteTube Dock
Version 0.1.0

概要

使用技術

開発者
Qtaro

開発支援
GPT / CODEX

セキュリティ方針
...
```

## 5. 文言の統一

アプリ内表示では以下の表記を使用する。

```text
LiteTube Dock
Version 0.1.0
開発者: Qtaro
開発支援: GPT / CODEX
```

既存の `LiteTube Dock` / `Version 0.1.0` 表記は維持すること。

## 6. README更新

READMEのバージョン情報または概要欄に、以下を追記する。

```text
開発者: Qtaro
開発支援: GPT / CODEX
```

README内にすでに同等の情報がある場合は、重複しないように整理する。
