# チケット033fix1: F12キーによる開発者ツール起動を無効化する

## 目的

チケット033で WebView 標準右クリックメニューを無効化し、右クリックから「開発者ツールで調査する」などが表示されないようにした。

しかし、現状では `F12` キーを押すと WebView2 の開発者ツールウィンドウが開いてしまう。

LiteTube Dock は視聴・常駐・簡易表示用のアプリとして扱う方針のため、通常利用時に開発者ツールを開けないようにする。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- チケット033で実装した WebView 標準右クリックメニュー無効化を維持する。
- 今回は `F12` キーによる開発者ツール起動の抑止のみを対象とする。
- YouTube / Google のログイン、認証情報、広告、DOM操作、YouTube内部APIまわりの処理仕様には触れない。
- YouTube広告を自動キャンセル、非表示、削除、置換、スキップする機能は実装しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。
- YouTubeページ内容の改変は行わない。
- 通報・報告機能を LiteTube Dock 側で独自実装しない。

## 対象ファイル

推定対象:

- `MainWindow.xaml`
- `MainWindow.xaml.cs`
- WebView2 初期化処理を持つ関連ファイル
- 必要に応じてヘルプ本文
  - `Constants/HelpContent.cs`
- 必要に応じて README
  - `README.md`

## 現状

右クリックメニューは無効化されているが、`F12` キーを押すと WebView2 の開発者ツールが開く。

これにより、右クリックメニューから開発者ツールを隠しても、キーボードショートカットから開けてしまう。

## 実装内容

### 1. WebView2 の開発者ツールを無効化する

WebView2 の設定で、開発者ツールを開けないようにする。

推奨実装:

```csharp
CoreWebView2.Settings.AreDevToolsEnabled = false;
```

要件:

- WebView2 初期化後、確実に設定すること。
- WebView2 が未初期化の状態でアクセスして例外を出さないこと。
- 通常モード・プレイヤーモードのどちらでも開発者ツールを開けないこと。
- `F12` キーを押しても DevTools ウィンドウが開かないこと。
- 右クリックメニュー無効化と併用しても問題ないこと。

### 2. F12キー入力も必要に応じて抑止する

`AreDevToolsEnabled = false` だけで足りない場合は、MainWindow 側で `F12` キー入力を明示的に抑止する。

候補:

- `PreviewKeyDown`
- `KeyDown`
- WebView2 側のキーイベント

要件:

- `F12` を押しても開発者ツールが開かない。
- 他の既存ショートカットを壊さない。
  - `Alt + ←`
  - `Alt + →`
  - `F5`
  - `Ctrl + R`
  - `Ctrl + H`
  - `Alt + Enter`
  - `Esc`
- テキスト入力やアドレスバー操作に悪影響を出さない。

### 3. 既存の開発者ツール導線を残さない

以下の導線から DevTools が開かないことを確認する。

- WebView 上で右クリック
- `F12`
- 必要に応じて `Ctrl + Shift + I`
- 必要に応じて `Ctrl + Shift + J`

ただし、今回の必須対象は `F12` とする。
`Ctrl + Shift + I` / `Ctrl + Shift + J` も同じ仕組みで無効化できる場合は、合わせて抑止する。

### 4. README / ヘルプの方針と矛盾しないようにする

チケット033で README / ヘルプに、LiteTube Dock は視聴・常駐・簡易表示用であり、詳細操作は通常ブラウザで行う旨を追記済み。

今回の修正はその方針と一致するため、必要であれば以下のような短い文言を追記してよい。

```text
LiteTube Dock では、通常利用向けに開発者ツールは使用できないようにしています。
```

ただし、README / ヘルプへの追記は必須ではない。
既存文面で十分なら変更しなくてよい。

## 実装時の注意

- WebView2 初期化後の適切なタイミングで設定する。
- `CoreWebView2` が null の状態でアクセスしない。
- 右クリックメニュー無効化処理を壊さない。
- 通常の動画視聴・スクロール・クリック操作を壊さない。
- アドレスバー入力・貼り付け・移動を壊さない。
- ナビゲーションボタンのショートカットを壊さない。
- フルスクリーン切替 `Alt + Enter` と `Esc` を壊さない。
- YouTubeページ内容を改変しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。

## 受け入れ条件（目視確認基準）

### TC-01: F12で開発者ツールが開かない

1. LiteTube Dock を起動する。
2. YouTubeページを表示する。
3. `F12` キーを押す。
4. 開発者ツールウィンドウが開かないことを確認する。
5. アプリがクラッシュしないことを確認する。

### TC-02: 右クリックメニュー無効化が維持されている

1. YouTubeページ上で右クリックする。
2. 標準ブラウザメニューが表示されないことを確認する。
3. `開発者ツールで調査する` が表示されないことを確認する。

### TC-03: 可能なら Ctrl+Shift+I / Ctrl+Shift+J でも開かない

1. YouTubeページを表示する。
2. `Ctrl + Shift + I` を押す。
3. 開発者ツールが開かないことを確認する。
4. `Ctrl + Shift + J` を押す。
5. 開発者ツールが開かないことを確認する。

※ この項目は、実装方式上対応しやすい場合に確認する。

### TC-04: 既存ショートカットが壊れていない

1. `Alt + ←` で前に表示していたページへ戻れることを確認する。
2. `Alt + →` で次のページへ進めることを確認する。
3. `F5` または `Ctrl + R` で再読み込みできることを確認する。
4. `Ctrl + H` でホームへ移動できることを確認する。
5. `Alt + Enter` でフルスクリーン切替できることを確認する。
6. `Esc` でフルスクリーン解除できることを確認する。

### TC-05: 通常操作に影響がない

1. YouTubeの動画を再生する。
2. ページをスクロールする。
3. アドレスバーからURL移動する。
4. お気に入りボタンからページ移動する。
5. いずれも通常通り動作することを確認する。

## 既存機能確認

- MainWindow が通常通り起動する。
- アドレスバーの URL入力・貼り付け・移動が動作する。
- 戻る、進む、再読み込み、ホームボタンが動作する。
- お気に入りボタンが動作する。
- 表示メニューの各項目が動作する。
- 設定画面を開閉できる。
- ヘルプ画面、バージョン情報画面を開ける。
- チケット033の右クリックメニュー無効化が維持されている。
- YouTube / Google のログイン、広告、DOM操作まわりの仕様変更が入っていない。

## 補足

このチケットは、チケット033の追加修正である。

チケット033では右クリックメニュー経由の開発者ツール導線を無効化したが、`F12` キーで開発者ツールが起動できる状態が残っていた。

LiteTube Dock の用途は視聴・常駐・簡易表示であるため、通常利用者向けには開発者ツールを開けない状態にする。
