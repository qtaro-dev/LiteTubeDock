# チケット022: ヘルプ画面先頭にロゴ画像を表示する

## 目的

LiteTube Dock のヘルプ画面は、目次や区切り線が入り読みやすくなってきたが、先頭部分はまだテキスト見出し中心で、やや簡素に見える。

ヘルプ画面の先頭に `LiteTubeDock_LogoLockup.png` を表示し、見栄えを改善して、アプリ全体の統一感を高める。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの仕様には触れない。
- 今回は HelpWindow の見た目改善のみを対象とする。
- ヘルプ画面はスクロールありのままでよい。

## 対象ファイル

推定対象:

- `HelpWindow.xaml`
- `HelpWindow.xaml.cs`
- 必要に応じて画像リソース参照設定
- `Resources/Images/LiteTubeDock_LogoLockup.png`

## 使用画像

以下の画像を使用する。

```text
E:\Dev\LiteTubeDock\Resources\Images\LiteTubeDock_LogoLockup.png
```

## 現状

ヘルプ画面の先頭は `LiteTube Dock` というテキスト見出しになっている。

目次やセクション区切りは整ってきているが、先頭がテキストだけのため、バージョン情報画面と比べると少し物足りない。

## 実装内容

### 1. ヘルプ画面先頭見出しをロゴ画像に置き換える

ヘルプ画面の最上部に表示している `LiteTube Dock` のテキスト見出しを、ロゴ画像表示に置き換える。

表示する画像:

- `Resources/Images/LiteTubeDock_LogoLockup.png`

### 2. ロゴ画像を見やすいサイズで表示する

ロゴ画像は横長のため、横幅を広めに使いつつ、画面からはみ出さないサイズにする。

方針:

- 横長ロゴとして自然に見えるサイズにする
- ウィンドウ幅を超えない
- 必要に応じて `Stretch="Uniform"` などで縦横比を維持する
- 大きすぎて本文開始位置が下がりすぎないようにする

### 3. ロゴの下に余白を入れる

ロゴ表示後すぐに目次が詰まって見えないように、ロゴの下に適度な余白を入れる。

期待イメージ:

- 先頭にロゴ
- 少し余白
- 目次
- 区切り線
- 各セクション本文

### 4. 既存の目次・区切り線・本文構成は維持する

以下は維持する。

- 目次
- 各セクション見出し
- 水平線や区切り
- 注意ボックス
- スクロール表示
- 右下の「閉じる」ボタン

今回は、ヘルプ画面の先頭部分の見た目改善が目的であり、本文内容の大規模変更は行わない。

### 5. 画像参照が安定するようにする

実行時にロゴ画像が正しく表示されるよう、WPFで適切な方法で画像を参照する。

必要に応じて確認すること:

- Build Action
- Copy to Output Directory
- Pack URI または相対パス参照
- 実行ファイル化後も表示されるか

## 実装時の注意

- 画像が横にはみ出さないようにする。
- ロゴが大きすぎてスクロール開始位置が不自然にならないようにする。
- 背景色とのコントラストを損なわないこと。
- ヘルプ画面全体の可読性を落とさないこと。
- 画像追加によって閉じるボタン位置やスクロール領域が崩れないようにする。
- AboutWindow 側のロゴ表示実装と大きく乖離しないよう、統一感を意識する。

## 受け入れ条件（目視確認基準）

### ヘルプ画面表示確認

1. LiteTube Dock を起動する。
2. メニューから `ヘルプ` を開く。
3. ヘルプ画面の先頭に `LiteTubeDock_LogoLockup.png` が表示されることを確認する。
4. 先頭の従来テキスト見出し `LiteTube Dock` が、ロゴ画像に置き換わっていることを確認する。
5. ロゴ画像が横にはみ出していないことを確認する。
6. ロゴの下に適度な余白があり、その下に `目次` が表示されることを確認する。
7. 既存の目次、区切り線、注意ボックス、本文が引き続き表示されることを確認する。
8. 右側スクロールバーで最後までスクロールできることを確認する。
9. 右下の `閉じる` ボタンで画面を閉じられることを確認する。

### 既存機能確認

- MainWindow が通常通り起動する。
- ヘルプ画面を複数回開閉しても例外が出ない。
- AboutWindow の表示に影響が出ていない。
- SettingsWindow の表示に影響が出ていない。
- YouTube / Google / WebView2 関連の挙動に変更が入っていない。

## 補足

将来的にヘルプ画面の先頭に短い説明文やバージョン表示を足したくなった場合でも、まずは今回のロゴ表示をベースにして、その下へ順に積む構成にすると整えやすい。

ただし今回は、ロゴ画像を先頭に置いてヘルプ画面の見栄えを改善することを主目的とする。
