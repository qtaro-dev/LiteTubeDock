# タスク名

チケット005fix3 ウィンドウ位置・サイズのデフォルト値リセット追加

# 目的

現在、LiteTube Dock にはウィンドウ位置・サイズの保存と復元、および画面外復旧処理がある。

しかし、ユーザーが設定画面から「ウィンドウ位置・サイズを初期値へ戻す」操作を行う手段が不足している。

マルチディスプレイ環境や手動サイズ変更により、ウィンドウ位置・サイズが扱いにくくなった場合に、設定画面から安全な既定値へ戻せるようにする。

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- 既存のMainWindow、SettingsWindowのレイアウトを全面的に作り直さないこと。

## 2. デフォルト値を定義する

ウィンドウ位置・サイズのデフォルト値を定数化する。

推奨値:

```text
DefaultWindowLeft = 100
DefaultWindowTop = 100
DefaultWindowWidth = 800
DefaultWindowHeight = 600
```

すでに同等の定数がある場合は、それを利用すること。

## 3. 設定画面にリセットボタンを追加する

`SettingsWindow.xaml` の基本設定画面に、ウィンドウ位置・サイズを初期値へ戻すボタンを追加する。

推奨表示名:

```text
ウィンドウ位置・サイズを初期値に戻す
```

推奨 `x:Name`:

```text
ResetWindowBoundsButton
```

配置場所:

- `ウィンドウサイズ` ドロップダウン
- `ウィンドウ幅`
- `ウィンドウ高さ`

の近くに配置すること。

既存の左カテゴリ型レイアウトは維持すること。

## 4. リセットボタン押下時の動作

`ResetWindowBoundsButton` 押下時に、設定画面上の入力値を以下へ戻す。

```text
WindowSizePresetComboBox = カスタム、または既定サイズに合うプリセット
WindowWidthTextBox = 800
WindowHeightTextBox = 600
```

さらに、MainWindow側へ即時反映できる構成の場合は、MainWindowを以下へ移動・リサイズする。

```text
Left = 100
Top = 100
Width = 800
Height = 600
```

即時反映が既存設計と合わない場合は、保存ボタン押下時に反映する形でもよい。

ただし、ユーザーが「保存」を押した後には必ずMainWindowへ反映されること。

## 5. 保存処理

リセット後に保存した場合、`settings.json` へ以下が保存されること。

```json
{
  "window": {
    "left": 100,
    "top": 100,
    "width": 800,
    "height": 600
  }
}
```

既存の `restoreWindowState` 設定は維持すること。

## 6. MainWindowの表示メニューとの整合性

すでに `表示` → `ウィンドウ位置をリセット` がある場合、その処理と矛盾しないようにする。

整理方針:

- `表示` → `ウィンドウ位置をリセット`
  - 位置のみを `Left=100`, `Top=100` へ戻す

- `設定画面` → `ウィンドウ位置・サイズを初期値に戻す`
  - 位置とサイズを両方既定値へ戻す

この違いを維持すること。

## 7. 画面外復旧との整合性

起動時の画面外復旧処理は維持すること。

ウィンドウ位置・サイズを初期値に戻した後は、画面外判定に引っかからない安全な位置で起動できること。

## 8. README更新

READMEに以下を追記する。

- 設定画面からウィンドウ位置・サイズを初期値へ戻せること
- 既定値は `Left=100`, `Top=100`, `Width=800`, `Height=600` であること
- 表示メニューの「ウィンドウ位置をリセット」は位置のみを戻すこと
- 設定画面のリセットは位置とサイズを戻すこと

## 9. 実装しないこと

今回のタスクでは以下を実装しない。

- モニター選択UI
- DPIごとの詳細設定
- 複数ウィンドウ対応
- フルスクリーン状態の保存
- UI全面再設計
- テーマ切り替え

# 受け入れ条件（目視確認基準）

## ビルド確認

- `dotnet build` でビルドエラーがない
- 警告が出る場合は内容を報告すること
- アプリ起動時にクラッシュしない

## 設定画面確認

- `設定` → `設定を開く` で設定画面が開く
- 左側の `基本設定` を押すと基本設定パネルが表示される
- 基本設定内に `ウィンドウ位置・サイズを初期値に戻す` ボタンが表示される
- レイアウトが大きく崩れていない

## リセット動作確認

- 設定画面で `ウィンドウ位置・サイズを初期値に戻す` を押す
- `ウィンドウ幅` が `800` になる
- `ウィンドウ高さ` が `600` になる
- 保存後、MainWindowが `Left=100`, `Top=100`, `Width=800`, `Height=600` 相当になる
- アプリを再起動しても既定位置・既定サイズが復元される

## 表示メニュー側との違い確認

- `表示` → `ウィンドウ位置をリセット` は位置のみリセットする
- 設定画面のリセットボタンは位置とサイズをリセットする

## 既存機能確認

- ウィンドウサイズプリセットのドロップダウンが壊れていない
- `800x600` / `960x540` / `1280x720` などのプリセット選択が動作する
- Home / Back / Forward / Reload が動作する
- お気に入りボタンでURL遷移できる
- フルスクリーン切り替えが壊れていない
- 設定保存が壊れていない
- YouTubeログイン情報、Google ID、パスワード、認証トークンは保存されていない
