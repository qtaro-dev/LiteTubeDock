# チケット033: WebView標準右クリックメニューを無効化し、詳細操作は通常ブラウザ案内に整理する

## 目的

LiteTube Dock は、YouTube や登録済みURLを軽量な専用ウィンドウで表示することを目的としたアプリである。

現在、YouTubeページ上で右クリックすると、WebView / ブラウザ標準の右クリックメニューが表示される場合がある。

このメニューには以下のような、LiteTube Dock の用途から外れやすい項目が含まれる。

- 名前を付けて保存
- 印刷
- その他のツール
- 開発者ツールで調査する
- ブラウザ標準の戻る / 更新

LiteTube Dock 側にはすでに、戻る・進む・再読み込み・ホーム・現在URLコピーなどの操作があるため、WebView標準の右クリックメニューは原則表示しない方針にする。

あわせて、YouTube側への報告・通報・コメント管理などの詳細操作は LiteTube Dock 内では対応せず、通常ブラウザで行う方針を README とヘルプに明記する。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- 今回は WebView標準右クリックメニューの抑止と、README / ヘルプ文言追記のみを対象とする。
- YouTube / Google のログイン、認証情報、広告、DOM操作、YouTube内部APIまわりの処理仕様には触れない。
- YouTube広告を自動キャンセル、非表示、削除、置換、スキップする機能は実装しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。
- YouTubeページ内容の改変は行わない。
- 通報・報告機能を LiteTube Dock 側で独自実装しない。

## 対象ファイル

推定対象:

- `MainWindow.xaml`
- `MainWindow.xaml.cs`
- `Constants/HelpContent.cs`
- `README.md`
- 必要に応じて WebView2 初期化処理を持つファイル

## 現状の課題

### 課題1: WebView標準右クリックメニューが表示される

YouTubeページ上で右クリックすると、ブラウザ標準メニューが表示される。

例:

```text
戻る
最新の情報に更新
名前を付けて保存
印刷
その他のツール
開発者ツールで調査する
```

LiteTube Dock は軽量視聴用アプリであり、これらの標準ブラウザメニューは用途から外れやすい。

### 課題2: YouTube側の詳細操作を LiteTube Dock 内で完結できるように見えてしまう

YouTubeのコメントやライブチャットには、三点リーダーなどから報告・通報などを行う導線がある。

ただし、LiteTube Dock 内では YouTube側の一部メニューが開けない場合がある。

これをアプリ側で無理に補完するために、DOM操作・自動クリック・YouTube内部API呼び出しなどを行うのは避けたい。

## 方針

LiteTube Dock の役割を以下のように整理する。

```text
LiteTube Dock = 視聴・常駐・簡易表示用
通常ブラウザ = YouTube側の詳細操作、報告・通報、コメント管理、保存、印刷などを行う場所
```

## 実装内容

### 1. WebView標準右クリックメニューを無効化する

WebView上で右クリックした時に、WebView / ブラウザ標準の右クリックメニューを表示しないようにする。

対象:

- YouTubeページ内
- 通常URL表示中のページ
- プレイヤーモード表示中のページ

想定実装:

- WebView2 の設定またはイベントで、標準コンテキストメニューを無効化する。
- 例: CoreWebView2 の設定や ContextMenuRequested 相当のイベントを利用する。

要件:

- 右クリックしても標準ブラウザメニューが出ないこと。
- アプリが例外で落ちないこと。
- 通常の左クリック操作、動画再生、スクロール、アドレスバー操作は維持すること。
- YouTubeページのDOMを書き換えないこと。
- YouTubeページ内のボタンを自動クリックしないこと。

### 2. LiteTube Dock側の操作ボタンは維持する

WebView標準右クリックメニューを無効化しても、LiteTube Dock 側の以下操作は維持する。

- 戻る
- 進む
- 再読み込み
- ホーム
- アドレスバー移動
- 現在URLコピー
- お気に入りボタン

標準右クリックメニュー内の「戻る」「更新」などは表示しないが、アプリ側ボタンで代替できる状態を維持する。

### 3. 報告・通報などのYouTube詳細操作は通常ブラウザで行う方針にする

LiteTube Dock 内では、YouTube側への報告・通報・コメント管理などの詳細操作は保証しない。

以下の趣旨を README とヘルプに明記する。

推奨文面:

```text
YouTube側に報告する通報機能、コメントやライブチャットの詳細メニューなど、一部のYouTube機能は本アプリ内では利用できない場合があります。
これらの操作が必要な場合は、現在URLをコピーして通常のブラウザで開いてください。
```

より短くする場合:

```text
YouTube側に報告する通報機能などは、本アプリでは利用できない場合があります。
必要な場合は、通常のブラウザで開いて操作してください。
```

### 4. READMEに方針を追記する

README に、LiteTube Dock の用途と制限として以下の趣旨を追記する。

追記候補セクション:

- 注意事項
- セキュリティ方針
- 制限事項
- LiteTube Dock について

追記内容に含めること:

- LiteTube Dock は視聴・常駐・簡易表示を目的にしている。
- WebView標準右クリックメニューは表示しない。
- YouTube側の通報・報告・コメント詳細操作などは本アプリ内では利用できない場合がある。
- 必要な場合は現在URLをコピーして通常ブラウザで開く。
- YouTube広告を自動キャンセル、非表示、削除、スキップする機能はない。
- YouTubeの仕様および利用条件を尊重している。

### 5. ヘルプに方針を追記する

`Constants/HelpContent.cs` のヘルプ本文にも、同じ趣旨をユーザー向けの分かりやすい文章で追記する。

候補セクション:

- LiteTube Dock について
- 外部遷移確認
- セキュリティ方針
- 注意事項

推奨文面:

```text
LiteTube Dock は、動画や登録済みURLをすばやく開くための簡易表示アプリです。
YouTube側に報告する通報機能、コメントやライブチャットの詳細メニューなど、一部のYouTube機能は本アプリ内では利用できない場合があります。
これらの操作が必要な場合は、現在URLをコピーして通常のブラウザで開いてください。
```

専門用語は控えめにすること。

### 6. 現在URLコピー導線を利用案内として扱う

YouTube側の通報・報告などが必要な場合は、既存の「現在URLをコピー」機能を使って通常ブラウザで開く運用にする。

新しい「通常ブラウザで開く」ボタンは今回必須ではない。

ただし、将来的に必要であれば別チケットで検討する。

## 実装時の注意

- WebView標準右クリックメニューを抑止しても、通常のページ表示や動画視聴を壊さない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。
- YouTubeページ内の通報UIをアプリ側で無理に開こうとしない。
- 通報機能を LiteTube Dock 側で代替実装しない。
- 右クリック抑止が原因でアプリが落ちないようにする。
- WebView2初期化前に設定へアクセスして例外を出さない。
- README とヘルプの文面は、ユーザー向けで分かりやすくする。
- `WebView2` などの専門用語はヘルプ本文ではなるべく使わない。
- 既存の広告ブロックではない旨の説明は維持する。
- 既存のセキュリティ方針は維持する。

## 受け入れ条件（目視確認基準）

### TC-01: WebView上で右クリックしても標準メニューが出ない

1. LiteTube Dock を起動する。
2. YouTubeページを表示する。
3. 動画周辺やページ上で右クリックする。
4. 以下のような標準ブラウザメニューが表示されないことを確認する。

```text
名前を付けて保存
印刷
その他のツール
開発者ツールで調査する
```

5. アプリがクラッシュしないことを確認する。

### TC-02: 既存操作ボタンは動作する

1. 戻るボタンを押す。
2. 前のページに戻れることを確認する。
3. 進むボタンを押す。
4. 次のページに進めることを確認する。
5. 再読み込みボタンを押す。
6. 現在ページを読み込み直せることを確認する。
7. ホームボタンを押す。
8. ホームURLへ移動できることを確認する。

### TC-03: 現在URLコピーが使える

1. YouTube動画ページまたはライブページを開く。
2. `現在URLをコピー` を押す。
3. 通常ブラウザのアドレスバーへ貼り付ける。
4. 同じページを通常ブラウザで開けることを確認する。

### TC-04: READMEに制限事項が追記されている

1. `README.md` を開く。
2. 以下の趣旨が記載されていることを確認する。

```text
YouTube側に報告する通報機能などは、本アプリでは利用できない場合があります。
必要な場合は、通常のブラウザで開いて操作してください。
```

3. 広告自動キャンセル、非表示、削除、スキップ機能がないことも引き続き記載されていることを確認する。

### TC-05: ヘルプに制限事項が追記されている

1. LiteTube Dock を起動する。
2. ヘルプ画面を開く。
3. 以下の趣旨が、ユーザー向けに分かりやすく記載されていることを確認する。

```text
YouTube側に報告する通報機能、コメントやライブチャットの詳細メニューなど、一部のYouTube機能は本アプリ内では利用できない場合があります。
必要な場合は、現在URLをコピーして通常のブラウザで開いてください。
```

4. ヘルプのレイアウトが崩れていないことを確認する。

### TC-06: 通常操作に影響がない

1. YouTubeの動画を再生する。
2. スクロールする。
3. アドレスバーからURL移動する。
4. お気に入りボタンからページ移動する。
5. いずれも通常通り動作することを確認する。

## 既存機能確認

- MainWindow が通常通り起動する。
- アドレスバーの URL入力・貼り付け・移動が動作する。
- 戻る、進む、再読み込み、ホームボタンが動作する。
- お気に入りボタンが動作する。
- 表示メニューの各項目が動作する。
- 設定画面を開閉できる。
- ヘルプ画面、バージョン情報画面を開ける。
- チケット029/030/031/032 のウィンドウサイズ・表示切替関連仕様が壊れていない。
- YouTube / Google のログイン、広告、DOM操作まわりの仕様変更が入っていない。

## 補足

このチケットの方針は、LiteTube Dock を「視聴・常駐・簡易表示用」として明確にすることである。

YouTube側の通報・報告・コメント管理などの詳細操作は、通常ブラウザで行う。

LiteTube Dock 側でYouTubeページを改変したり、YouTube内部機能を代替実装したりしない。
