# チケット025fix1: お気に入り設定カードの番号帯に背景色・文字色を反映する

## 目的

チケット025で、お気に入りボタン設定カードの左側にスロット番号帯を追加した。

現在は番号帯が固定色になっているが、設定画面上の「背景色」「文字色」と番号帯の見た目が連動していないため、ユーザーが設定中のボタン色を直感的に確認しづらい。

番号帯を、各お気に入りボタンの簡易プレビューとして機能させる。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの仕様には触れない。
- 今回は SettingsWindow の「お気に入りボタン」設定カード左側の番号帯表示改善のみを対象とする。
- 設定画面は固定サイズのまま扱う。
- チケット025の追加修正として扱う。

## 対象ファイル

推定対象:

- `Views/FavoriteButtonsSettingsView.xaml`
- `Views/FavoriteButtonsSettingsView.xaml.cs`
- 必要に応じてお気に入りボタン設定カード生成処理
- 必要に応じてお気に入りモデル
- 必要に応じてカラー変換処理、Brush変換処理

## 現状

お気に入り設定カード左側に、濃いグレー背景・白文字の番号帯が表示されている。

ただし、各カード内にある以下の設定とは連動していない。

- 背景色
- 文字色

そのため、番号帯が実際のお気に入りボタン設定のプレビューになっていない。

## 実装内容

### 1. 番号帯の背景色を「背景色」設定と連動させる

各お気に入り設定カードの左側番号帯の背景色を、そのカードの「背景色」入力欄の値と連動させる。

例:

```text
背景色: #FF8000
```

の場合、左側番号帯の背景も `#FF8000` になる。

ユーザー意図:

```text
スクリーンショット赤線部分 = 背景色入力欄と同じ色
```

### 2. 番号帯の文字色を「文字色」設定と連動させる

各お気に入り設定カードの左側番号帯に表示している `01` `02` などの文字色を、そのカードの「文字色」入力欄の値と連動させる。

例:

```text
文字色: #FFFFFF
```

の場合、左側番号帯の番号文字色も `#FFFFFF` になる。

ユーザー意図:

```text
スクリーンショット黄色線部分 = 文字色入力欄と番号文字色が同じ色
```

### 3. 入力値変更時に番号帯も即時反映する

可能であれば、背景色・文字色の入力欄を変更したタイミングで、番号帯の表示も即時更新する。

期待挙動:

- 背景色欄を `#FF8000` に変更する
- 番号帯の背景色が `#FF8000` になる
- 文字色欄を `#FFFFFF` に変更する
- 番号帯の番号文字色が `#FFFFFF` になる

即時反映が難しい場合でも、以下のいずれかで反映されること。

- フォーカスアウト時
- 保存前の画面更新時
- 設定画面を開き直した時

ただし、できるだけ即時反映を優先する。

### 4. 無効なカラー入力時のフォールバックを用意する

背景色・文字色の入力欄に無効な値が入った場合でも、アプリが落ちないようにする。

例:

```text
abc
#GGGGGG
空文字
```

無効な値の場合の推奨フォールバック:

- 背景色: `#111111` または既存の固定濃色
- 文字色: `#FFFFFF`
- 既存のエラー処理がある場合は、それに合わせる

要件:

- 無効なカラー値でも例外で落ちない。
- 入力中に一時的に不完全なカラーになっても、画面がクラッシュしない。
- 既存の保存時バリデーションがある場合は壊さない。

### 5. 番号帯のレイアウトは維持する

チケット025で追加した番号帯レイアウトは維持する。

維持したい要素:

- カード左側の縦長エリア
- `01` `02` などの2桁番号表示
- 大きめの番号文字
- 番号の中央配置
- 右側の既存フォームレイアウト

### 6. 保存データ形式は変更しない

今回の修正は表示連動のみを目的とする。

- `bookmarks.json` の保存形式を変更しない。
- 既存の背景色・文字色プロパティをそのまま使う。
- 新しい保存項目は追加しない。

## 実装時の注意

- 既存の `x:Name` は原則維持する。
- 既存の保存処理・キャンセル処理を壊さない。
- 背景色・文字色の入力欄と番号帯の双方向反映で無限ループを起こさない。
- 無効なカラー入力で例外が出ないようにする。
- 入力中のカラー文字列が一時的に不完全でも画面が固まらないようにする。
- 右側の色プレビュー四角がある場合、その既存挙動も壊さない。
- 番号帯の背景色と番号文字色が同系色で見づらくなる可能性は許容する。
  - これはユーザーが設定した色のプレビューとして扱うため。
- MainWindow のお気に入りボタン表示仕様は今回の対象外とする。
- YouTube / Google / WebView2 関連の処理には触れない。

## 受け入れ条件（目視確認基準）

### 背景色連動確認

1. LiteTube Dock を起動する。
2. 設定画面を開く。
3. 左カテゴリで「お気に入りボタン」を選択する。
4. 任意のカードの「背景色」欄に以下を入力する。

```text
#FF8000
```

5. そのカード左側の番号帯背景色が `#FF8000` 相当のオレンジ色になることを確認する。

### 文字色連動確認

1. 同じカードの「文字色」欄に以下を入力する。

```text
#FFFFFF
```

2. 番号帯の `01` などの番号文字色が白になることを確認する。

### 別カード独立確認

1. 2番目のカードの背景色を以下にする。

```text
#F0F0F0
```

2. 2番目の番号帯だけがその色になることを確認する。
3. 1番目のカードの番号帯色が勝手に変わらないことを確認する。

### 無効カラー確認

1. 背景色欄に以下のような無効値を入力する。

```text
abc
```

2. アプリが例外で落ちないことを確認する。
3. 番号帯がフォールバック色、または直前の有効色で表示されることを確認する。

### 保存・復元確認

1. 背景色と文字色を変更する。
2. 「保存」を押す。
3. 設定画面を閉じる。
4. 再度設定画面を開く。
5. 保存した背景色・文字色が入力欄に表示されることを確認する。
6. 番号帯にも保存済みの背景色・文字色が反映されていることを確認する。

### 既存機能確認

- 表示名を編集できる。
- URLを編集できる。
- アイコン選択ボタンが使える。
- 背景色と文字色の既存プレビューがある場合、それも壊れていない。
- 形状コンボボックスを変更できる。
- 各チェックボックスを操作できる。
- 削除ボタンが押せる。
- 有効チェックが操作できる。
- お気に入りボタン設定一覧をスクロールできる。
- 下部の「初期値に戻す」「キャンセル」「保存」ボタンが固定表示される。
- 基本設定画面に影響が出ていない。
- MainWindow のお気に入りボタン表示が壊れていない。
- YouTube / Google / WebView2 関連の挙動に変更が入っていない。

## 補足

ユーザーが求めている見た目は、単なる黒い番号帯ではなく、各お気に入りボタンの色設定を左側番号帯にも反映した簡易プレビューである。

スクリーンショット上の意図:

- 赤線で囲った左側番号帯の背景 = 背景色入力欄の色
- 黄色線で囲った番号文字 = 文字色入力欄の色

完全なボタンプレビュー化までは不要だが、番号帯を見るだけで「このスロットの背景色と文字色」が分かる状態を目標とする。
