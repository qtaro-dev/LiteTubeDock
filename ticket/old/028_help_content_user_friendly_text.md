# チケット028: ヘルプ本文を専門用語控えめなユーザー向け文章に置き換える

## 目的

現在のヘルプ本文には、`WebView2` など一般ユーザーには分かりづらい技術用語が含まれている。

LiteTube Dock のヘルプは、開発者向けの技術説明ではなく、アプリを使う人が操作方法を理解するための説明書として扱いたい。

そのため、`E:\Dev\LiteTubeDock\Constants\HelpContent.cs` のヘルプ本文を、専門用語を控えた分かりやすい文章に置き換える。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- ユーザー側でバックアップ取得済み。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- 今回はヘルプ本文の文言修正のみを対象とする。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの処理仕様には触れない。
- YouTube広告を自動キャンセル、非表示、削除、置換、スキップする機能は実装しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。

## 対象ファイル

```text
E:\Dev\LiteTubeDock\Constants\HelpContent.cs
```

## 現状の課題

ヘルプ本文内に、以下のような技術寄りの表現がある。

```text
WebView2へ遷移
WebView2の履歴
WebView2標準のCookie / Session管理
DOM操作
YouTube API
```

これらは開発者には意味が分かるが、通常の利用者には伝わりづらい。

ヘルプ本文では、技術名よりも「何ができるか」「どう操作するか」「何に注意すればよいか」が分かる表現にしたい。

## 実装内容

### 1. `WebView2` という表現をユーザー向けに置き換える

ヘルプ本文では、原則として `WebView2` という技術名を出さない。

置き換え候補:

```text
WebView2
→ アプリ内の表示エリア
→ LiteTube Dock内の画面
→ ページ表示エリア
→ アプリ内で表示しているページ
```

例:

```text
URLを入力して Enter、または 移動ボタンでWebView2へ遷移できます。
```

修正例:

```text
URLを入力して Enter、または 移動ボタンを押すと、そのページをLiteTube Dock内に表示します。
```

### 2. 戻る・進むの説明を分かりやすくする

技術的な履歴表現ではなく、普段のブラウザ操作に近い説明にする。

修正例:

```text
戻る: 戻るボタン、または Alt + ← で前に表示していたページへ戻ります。
進む: 進むボタン、または Alt + → で次のページへ進みます。
```

### 3. 再読み込み・ホームの説明を分かりやすくする

修正例:

```text
再読み込み: 再読み込みボタン、または F5 / Ctrl + R で現在のページを読み込み直します。
ホーム: ホームボタン、または Ctrl + H で設定済みのホームURLへ移動します。
```

### 4. アドレスバー説明を分かりやすくする

修正例:

```text
URLを入力して Enter、または 移動ボタンを押すと、そのページをLiteTube Dock内に表示します。
http:// または https:// がない場合は、https:// を自動で補います。
YouTube内で動画やライブへ移動した場合、現在表示しているページのURLをアドレスバーに反映します。
```

### 5. 外部遷移確認の説明を分かりやすくする

専門用語を避け、「YouTube以外のページへ移動する時の確認」として説明する。

修正例:

```text
誤クリック防止として、YouTube以外のページへ移動しようとした場合に確認を表示します。
通常のページ移動だけでなく、新しいウィンドウで開こうとするリンクにも確認を表示します。
アドレスバー、Home、Reload、お気に入りボタンなど、ユーザーが明示的に操作した移動は確認なしで実行します。
```

### 6. 広告関連の注意書きは分かりやすく維持する

以下の趣旨は必ず残す。

```text
LiteTube Dock には、YouTube広告を自動でキャンセル、非表示、削除、スキップする機能はありません。
```

文面は自然に整えてよい。

### 7. プレイヤーモード説明を専門用語控えめにする

`embed` などの表現は必要最小限にする。

修正例:

```text
プレイヤーモードは、YouTubeの埋め込み再生形式を使って動画を表示する実験的な機能です。
動画によっては再生できない場合があります。
再生できない場合は、通常モードを使用してください。
```

以下の趣旨も残す。

```text
LiteTube Dock は、YouTubeページ内のボタンを自動で押したり、ページ内容を書き換えたりする操作は行いません。
```

### 8. セキュリティ方針を一般ユーザー向けにする

技術用語を必要以上に出さず、何を保存しないかを明確にする。

修正例:

```text
LiteTube Dock は、YouTube / Googleログイン機能を独自に実装しません。
ログインはYouTubeの画面上で、ユーザー自身が行ってください。
Google ID、パスワード、認証トークンは保存しません。
ログイン状態を完全にリセットしたい場合は、アプリ終了後に data/webview2-user-data を削除してください。
```

`Cookie / Session` などの用語は、必要なら以下のように補足的に使う。

```text
ログイン状態は、アプリ内ブラウザの標準機能に任せます。
```

### 9. 使用技術の説明はヘルプ本文から外してよい

ヘルプはユーザー向け説明書として扱う。

そのため、以下のような使用技術一覧はヘルプ本文に必須ではない。

```text
.NET 8
WPF
C#
Microsoft Edge WebView2
JSON settings
```

必要な場合は、バージョン情報画面に残す程度でよい。

### 10. 既存のヘルプ構成は維持する

以下の構成は維持する。

- ロゴ表示
- 目次
- セクション見出し
- 区切り線
- 注意ボックス
- スクロール表示
- 閉じるボタン

今回の対象は本文の文言調整であり、レイアウトの大規模変更は行わない。

## 文体方針

- 一般ユーザー向けの説明にする。
- 専門用語をできるだけ避ける。
- 1文を長くしすぎない。
- 操作名は分かりやすく書く。
- 「何を押すと、何が起きるか」が分かる文章にする。
- 技術仕様ではなく、使い方説明に寄せる。

## 実装時の注意

- `HelpContent.cs` の構造を大きく壊さない。
- ヘルプ表示処理が期待しているデータ形式を維持する。
- 文字列置換によりビルドエラーを起こさない。
- 改行、エスケープ、引用符の扱いに注意する。
- 注意書きの意味を弱めない。
- YouTubeの仕様・利用条件を尊重していることは残す。
- 広告自動キャンセル機能がないことは残す。
- セキュリティ方針で、Google ID、パスワード、認証トークンを保存しないことは残す。
- YouTube / Google / WebView2 関連の処理には触れない。

## 受け入れ条件（目視確認基準）

### ヘルプ文面確認

1. LiteTube Dock を起動する。
2. ヘルプ画面を開く。
3. ヘルプ本文に `WebView2へ遷移` のような開発者向け表現が残っていないことを確認する。
4. 「戻る」「進む」「再読み込み」「ホーム」の説明が、一般ユーザーにも分かる表現になっていることを確認する。
5. アドレスバー説明が「アプリ内に表示します」など自然な表現になっていることを確認する。
6. 外部遷移確認の説明が、YouTube以外のページへ移動する時の確認として分かりやすいことを確認する。
7. プレイヤーモードが実験的機能であり、再生できない場合があることが分かることを確認する。
8. 広告を自動キャンセル、非表示、削除、スキップする機能がないことが明記されていることを確認する。
9. Google ID、パスワード、認証トークンを保存しないことが明記されていることを確認する。

### 表示確認

1. ヘルプ画面のロゴ、目次、見出し、区切り線、注意ボックスが崩れていないことを確認する。
2. ヘルプ画面をスクロールして最後まで読めることを確認する。
3. 閉じるボタンでヘルプ画面を閉じられることを確認する。

### ビルド確認

- `dotnet build` が成功する。
- 警告、エラーが新たに増えていないことを確認する。

### 既存機能確認

- MainWindow が通常通り起動する。
- アドレスバーの URL入力・貼り付け・移動が動作する。
- 戻る、進む、再読み込み、ホームボタンが動作する。
- お気に入りボタンが動作する。
- 設定画面、バージョン情報画面を開ける。
- YouTube / Google / WebView2 関連の処理に変更が入っていない。

## 補足

このチケットは、ヘルプ本文の技術用語を減らし、普通の利用者が読みやすい説明書にするためのもの。

使用技術はヘルプ本文に必須ではない。
必要であれば、技術情報はバージョン情報画面側に残す。
