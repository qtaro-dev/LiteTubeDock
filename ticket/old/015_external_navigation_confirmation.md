# タスク名

チケット015 外部リンク遷移確認と誤クリック防止

# 目的

LiteTube Dock は、YouTube動画・ライブ・登録済みURLを小さな専用ウィンドウで表示する用途で使用する。

しかし、YouTube画面内のスポンサーリンク、外部リンク、関連導線などを誤クリックすると、意図せず動画ページ以外へ遷移してしまう場合がある。

この機能は広告ブロックではなく、誤クリック防止のための遷移確認である。

YouTube外、または動画ページ以外と思われるURLへ遷移しようとした場合に、以下の確認メッセージを表示する。

```text
動画ページ以外へ移動しようとしています。
遷移してよろしいですか？
```

ユーザーが許可した場合のみ遷移し、キャンセルした場合は遷移を止める。

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- MainWindow、SettingsWindow、HelpWindow、AboutWindow、既存機能を壊さないこと。
- YouTube広告をブロック、非表示、改変、置換、スキップする機能として実装しないこと。
- YouTubeのDOM操作や内部API操作は行わないこと。

## 2. WebView2の遷移前イベントで確認する

WebView2がページ遷移しようとした時、遷移先URLを確認する。

実装候補:

```csharp
PlayerWebView.CoreWebView2.NavigationStarting
```

または、既存で利用している遷移開始イベントに合わせること。

処理概要:

```text
NavigationStarting
↓
遷移先URLを取得
↓
許可対象URLか判定
↓
許可対象でない場合は確認ダイアログを表示
↓
ユーザーがキャンセルした場合は e.Cancel = true
```

## 3. 確認メッセージ

動画ページ以外へ移動しようとした場合、以下の文言で確認する。

```text
動画ページ以外へ移動しようとしています。
遷移してよろしいですか？
```

ボタンは以下でよい。

```text
はい / いいえ
```

または

```text
OK / キャンセル
```

推奨:

- `はい`: 遷移する
- `いいえ`: 遷移しない

## 4. 広告・スポンサーと断定しない

確認メッセージでは、広告やスポンサーと断定しないこと。

使用しない文言例:

```text
広告リンクです
スポンサーです
広告をブロックしました
広告を非表示にしました
```

理由:

- YouTube内の通常リンクやチャンネルリンクを広告と誤判定する可能性がある
- この機能の目的は広告ブロックではなく、誤クリック防止であるため

## 5. 許可対象URL

まずは安全で使いやすい判定として、以下を許可対象にする。

許可対象:

- `https://www.youtube.com/`
- `https://youtube.com/`
- `https://m.youtube.com/`
- `https://youtu.be/`
- `https://www.youtube-nocookie.com/`

許可対象の例:

```text
https://www.youtube.com/
https://www.youtube.com/watch?v=...
https://www.youtube.com/live/...
https://www.youtube.com/shorts/...
https://www.youtube.com/embed/...
https://youtu.be/...
```

## 6. 確認対象URL

以下は確認対象とする。

- YouTube以外の外部ドメイン
- `http://` の外部URL
- 不明なスキーム
- `mailto:`
- `tel:`
- その他、通常の動画視聴では不要な外部遷移

確認対象の例:

```text
https://example.com/
https://sponsor.example.com/
mailto:...
tel:...
```

## 7. YouTube内リンクの扱い

初期実装では、YouTubeドメイン内のリンクは基本的に許可してよい。

理由:

- YouTubeトップ、動画、ライブ、チャンネル、検索、ログイン画面など、必要な通常操作があるため
- 厳しくしすぎると使い勝手が悪くなるため

ただし、将来的に「動画ページのみ許可」モードを追加しやすいよう、URL判定処理は小さく分離すること。

## 8. 設定項目を追加する

誤クリック防止機能のON/OFFを設定として追加する。

表示名:

```text
動画ページ以外への遷移を確認する
```

推奨 `x:Name`:

```text
ConfirmNonVideoNavigationCheckBox
```

配置場所:

- 設定画面 `基本設定`
- 自動再生やプレイヤーモードReferer設定の近く
- または基本設定下部

既定値:

```text
true
```

理由:

- 誤クリック防止が目的なので初期状態で有効にする
- 使いにくい場合はユーザーがOFFにできるようにする

## 9. AppSettingsへ項目追加

`Models/AppSettings.cs` に設定を追加する。

推奨プロパティ:

```csharp
public bool ConfirmNonVideoNavigation { get; set; }
```

JSON例:

```json
{
  "confirmNonVideoNavigation": true
}
```

既定値:

```text
true
```

## 10. settings.jsonへの保存・復元

`SettingsService` で `confirmNonVideoNavigation` を保存・復元する。

仕様:

- 初回起動時、未指定なら `true`
- 設定画面でON/OFFできる
- 再起動後もON/OFF状態が復元される
- 不正値ではクラッシュしない

## 11. 設定の即時反映

設定画面で `動画ページ以外への遷移を確認する` を変更して保存した場合、可能であればアプリ再起動なしで即時反映する。

期待動作:

```text
設定OFFで保存
↓
外部リンク確認なしで遷移

設定ONで保存
↓
外部リンク遷移時に確認
```

既存の設定即時反映処理がある場合は、それに合わせること。

## 12. アドレスバー入力との整合性

アドレスバーへユーザーが明示的に外部URLを入力して `移動` した場合も確認対象にするかどうかを決める。

推奨:

- アドレスバー入力はユーザーが明示的に入力しているため、確認なしで遷移してよい
- ただし実装が複雑になる場合は、初期実装ではNavigationStartingの共通判定に任せてもよい

望ましい方針:

```text
WebView内クリックによる外部遷移: 確認する
アドレスバーからの明示的な外部URL移動: 確認しない
```

実装する場合は、アドレスバーからの遷移時に一時フラグを立て、NavigationStartingで確認をスキップする。

## 13. お気に入りボタンとの整合性

お気に入りボタンにYouTube以外のURLを登録している場合は、ユーザーが登録したURLであるため確認なしで開いてよい。

望ましい方針:

```text
お気に入りボタンからの遷移: 確認しない
WebView内クリックによる外部遷移: 確認する
```

実装する場合は、お気に入りボタン遷移時に一時フラグを立て、NavigationStartingで確認をスキップする。

## 14. Home / Back / Forward / Reloadとの整合性

以下の既存操作が壊れないようにする。

- Home
- Back
- Forward
- Reload

方針:

- Homeはアプリ設定のホームURLなので確認なしでよい
- Reloadは同一ページ再読み込みなので確認なしでよい
- Back / Forward は、外部ページへ戻る可能性があるため、初期実装では確認対象でもよい
- ただし、ユーザー操作であるため使い勝手を見て調整しやすい構造にする

## 15. プレイヤーモードとの整合性

プレイヤーモードのYouTube embed URLはYouTubeドメインとして許可する。

許可例:

```text
https://www.youtube.com/embed/...
```

プレイヤーモード診断やReferer設定を壊さないこと。

## 16. ステータスバー表示

遷移をキャンセルした場合、可能であればステータスバーへ短い状態を表示する。

例:

```text
状態: 動画ページ以外への遷移をキャンセルしました
```

必須ではないが、ユーザーに分かりやすい。

## 17. README更新

READMEに以下を追記する。

- 確認メッセージ文言

- YouTube広告を非表示・削除・スキップするものではないこと

## 18. ヘルプ更新

# 受け入れ条件（目視確認基準）

## ビルド確認

- `dotnet build` でビルドエラーがない
- 警告が出る場合は内容を報告すること
- アプリ起動時にクラッシュしない

## 設定画面確認

- `設定` → `設定を開く` → `基本設定` を表示する
- `動画ページ以外への遷移を確認する` チェックボックスが表示される
- 初期値はONである
- ON/OFFを変更して保存できる
- 再起動後もON/OFF状態が復元される
- `settings.json` に `confirmNonVideoNavigation` が保存される

## 外部リンク確認

- 確認ONの状態で、WebView内からYouTube以外のURLへ移動しようとする
- 以下の確認メッセージが表示される

```text
動画ページ以外へ移動しようとしています。
遷移してよろしいですか？
```

- `いいえ` または `キャンセル` を選ぶと遷移しない
- `はい` または `OK` を選ぶと遷移する

## YouTube内遷移確認

- YouTubeトップへ移動できる
- YouTube動画ページへ移動できる
- YouTubeライブページへ移動できる
- YouTubeショートへ移動できる
- YouTubeチャンネルページへ移動できる
- これらで不要な確認が頻発しない

## 設定OFF確認

- `動画ページ以外への遷移を確認する` をOFFにして保存する
- 外部URLへ移動しても確認が出ない
- ONに戻すと確認が出る

## 広告ブロックではないことの確認

- YouTube広告を非表示にしない
- YouTube広告をスキップしない
- YouTubeプレイヤー上の広告表示を改変しない
- DOM操作や内部API操作をしていない

- お気に入りボタンの色・アイコン表示が壊れていない
- リジューム設定が壊れていない
- インポート/エクスポートが壊れていない
- フルスクリーン切り替えが壊れていない
- ウィンドウサイズプリセットが壊れていない
