# 共通前提（必ず遵守）

- AGENT.md が存在する場合、その内容を最優先で遵守させること
- ユーザーはコードを直接編集しない前提である
- 実装・修正はすべて CODEX が行う
- 既存設計を破壊しない
- 既存テーマ・ライブラリ構成を維持する
- ハードコード文字列は禁止
- ICommand構造を崩さない

# タスク名

ログメニューをトップレベルメニューへ移動

# 目的

LiteTubeDockのトップメニューを以下の並びへ変更する。

```text
ファイル　表示　設定　ログ　ヘルプ
```

現在「ファイル」メニュー配下に入っている「ログ」サブメニューを廃止し、「ログ」をトップレベルメニューとして独立表示する。

ログ関連機能である「ログを表示」「ログフォルダーを開く」は、新しいトップレベルの「ログ」メニュー配下へ移動する。

# 対象ファイル（推定可）

- `E:\Dev\LiteTubeDock\MainWindow.xaml`
- `E:\Dev\LiteTubeDock\MainWindow.xaml.cs`
- `E:\Dev\LiteTubeDock\Constants\UiTextConstants.cs`
- `E:\Dev\LiteTubeDock\Resources\Strings.xaml`
- その他、トップメニュー定義、ログウィンドウ表示、ログフォルダー表示に関係するファイル

# 実装内容（具体的変更指示）

1. LiteTubeDockのトップメニュー構成を以下の順序へ変更すること。

   ```text
   ファイル
   表示
   設定
   ログ
   ヘルプ
   ```

2. 「ログ」は「ファイル」メニュー内の子項目ではなく、トップレベルメニューとして表示すること。

3. 現在「ファイル」メニュー配下に存在する「ログ」サブメニューを削除すること。

4. 新しいトップレベル「ログ」メニューの配下へ、以下の項目を配置すること。

   ```text
   ログ
   ├ ログを表示
   └ ログフォルダーを開く
   ```

5. 「ログを表示」の既存機能は変更しないこと。

6. 「ログを表示」を押した場合、チケット038で実装したログ専用ウィンドウを開くこと。

7. ログ専用ウィンドウがすでに開いている場合は、重複して新規作成せず、既存ウィンドウを前面へ表示すること。

8. 「ログフォルダーを開く」の既存機能は変更しないこと。

9. 「ログフォルダーを開く」を押した場合、既存ログ保存先をエクスプローラーで開くこと。

10. 「ファイル」メニューには、ログ関連項目を残さないこと。

11. 「ファイル」メニューには、既存の以下の項目だけを維持すること。

   - お気に入り設定をインポート
   - お気に入り設定をエクスポート
   - 終了
   - その他、既存のファイル操作項目があればそれら

12. 「表示」「設定」「ヘルプ」の既存トップレベルメニュー構成と機能は変更しないこと。

13. トップメニューの表示順が必ず以下になること。

   ```text
   ファイル → 表示 → 設定 → ログ → ヘルプ
   ```

14. 「ログ」を「ヘルプ」の後ろや「設定」の前へ配置しないこと。

15. 既存のクリックイベント、ICommand、ログウィンドウ管理処理を再利用すること。

16. ログ関連処理を重複実装しないこと。

17. メニュー移動によって、ログ専用ウィンドウ内の以下の機能へ影響を与えないこと。

   - 再読み込み
   - 全文コピー
   - ログフォルダーを開く
   - 自動更新
   - 更新時に最下部へ移動
   - 検索
   - 範囲選択
   - `Ctrl+A`
   - `Ctrl+C`
   - 右クリックコピー

18. 新しいトップレベル「ログ」の表示文言は、既存のリソース管理方式に従い、ハードコードしないこと。

19. トップメニューの見た目、フォント、高さ、余白、ホバー、選択状態は既存テーマを維持すること。

20. 実装後、Debug構成でビルドし、警告0・エラー0を確認すること。

# 受け入れ条件（目視確認基準）

## トップメニュー

1. テスターがLiteTubeDockを起動する。
2. ウィンドウ上部のトップメニューを確認する。
3. 以下の順序で横並び表示されていることを確認する。

   ```text
   ファイル　表示　設定　ログ　ヘルプ
   ```

4. 「ログ」がトップレベルメニューとして独立していることを確認する。
5. 「ログ」が「ファイル」メニュー内に入っていないことを確認する。

## ファイルメニュー

1. 「ファイル」メニューを開く。
2. 「ログ」サブメニューが存在しないことを確認する。
3. 「ログを表示」が存在しないことを確認する。
4. 「ログフォルダーを開く」が存在しないことを確認する。
5. お気に入り設定のインポート、エクスポート、終了が従来どおり表示されることを確認する。

## ログメニュー

1. トップレベルの「ログ」を開く。
2. 以下の項目が表示されることを確認する。

   - ログを表示
   - ログフォルダーを開く

3. 「ログを表示」を押す。
4. ログ専用ウィンドウが開くことを確認する。
5. 再度「ログを表示」を押しても、ログウィンドウが重複して増えないことを確認する。
6. 「ログフォルダーを開く」を押す。
7. 既存ログ保存先がエクスプローラーで開くことを確認する。

## 表示順

1. トップメニューの並びを左から確認する。
2. 「ファイル」の次が「表示」であることを確認する。
3. 「表示」の次が「設定」であることを確認する。
4. 「設定」の次が「ログ」であることを確認する。
5. 「ログ」の次が「ヘルプ」であることを確認する。

## 回帰確認

- お気に入り設定のインポートが動作すること
- お気に入り設定のエクスポートが動作すること
- 「表示」メニューが従来どおり動作すること
- 「設定」メニューが従来どおり動作すること
- 「ヘルプ」メニューが従来どおり動作すること
- ログ専用ウィンドウの再読み込み、コピー、自動更新、検索が動作すること
- 「終了」が動作すること
- WebView2、IPC、設定画面、About画面へ影響がないこと
- Debug構成で警告0・エラー0でビルド成功すること
