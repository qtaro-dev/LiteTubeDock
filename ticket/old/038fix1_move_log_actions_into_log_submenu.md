# タスク名

ログ関連メニューのサブメニュー化

# 目的

LiteTubeDockの「ファイル」メニュー直下に並んでいるログ関連項目を整理し、「ログ」を親メニューとするサブメニュー構成へ変更する。

現在の「ログを表示」「ログフォルダーを開く」の機能は維持しつつ、今後ログ関連機能を追加しやすいメニュー構成にする。

# 対象ファイル（推定可）

- `E:\Dev\LiteTubeDock\MainWindow.xaml`
- `E:\Dev\LiteTubeDock\MainWindow.xaml.cs`
- `E:\Dev\LiteTubeDock\Constants\UiTextConstants.cs`
- `E:\Dev\LiteTubeDock\Resources\Strings.xaml`
- その他、メニュー定義とログウィンドウ起動処理に関係するファイル

# 実装内容（具体的変更指示）

1. 「ファイル」メニュー直下にある以下の項目を、そのまま直下へ表示しないよう変更すること。

   - ログを表示
   - ログフォルダーを開く

2. 「ファイル」メニュー直下へ、新しい親メニューを追加すること。

   ```text
   ログ
   ```

3. 「ログ」親メニューの配下へ、以下の項目を配置すること。

   ```text
   ログ
   ├ ログを表示
   └ ログフォルダーを開く
   ```

4. 既存の「ログを表示」機能は変更しないこと。

5. 「ログを表示」を押した場合、チケット038で実装したログ専用ウィンドウが開くこと。

6. ログ専用ウィンドウがすでに開いている場合は、重複起動せず既存ウィンドウを前面へ表示すること。

7. 既存の「ログフォルダーを開く」機能は変更しないこと。

8. 「ログフォルダーを開く」を押した場合、既存ログ保存先をエクスプローラーで開くこと。

9. ファイルメニュー全体の表示順を、以下のように整理すること。

   ```text
   ファイル
   ├ お気に入り設定をインポート
   ├ お気に入り設定をエクスポート
   ├ 区切り線
   ├ ログ
   │  ├ ログを表示
   │  └ ログフォルダーを開く
   ├ 区切り線
   └ 終了
   ```

10. 既存メニューの「お気に入り設定をインポート」「お気に入り設定をエクスポート」「終了」は変更しないこと。

11. ログ関連メニューをサブメニュー化しても、既存のクリックイベント、ICommand、ウィンドウ管理処理を再利用すること。

12. 同じ処理を重複実装しないこと。

13. メニュー項目のアクセスキーやショートカットが既に存在する場合は維持すること。

14. 新規の親メニュー「ログ」の表示文言は、既存のリソース管理方式に従い、ハードコードしないこと。

15. メニュー階層化によって、ログウィンドウの再読み込み、全文コピー、自動更新、検索等の既存機能へ影響を与えないこと。

16. メニューを開いた際、サブメニューの表示位置やクリック領域が不自然にならないこと。

17. LiteTubeDockの既存テーマ、フォント、メニュー表示スタイルを維持すること。

18. 実装後、Debug構成でビルドし、警告0・エラー0を確認すること。

# 受け入れ条件（目視確認基準）

## ファイルメニュー

1. テスターがLiteTubeDockを起動する。
2. 「ファイル」メニューを開く。
3. 「ログを表示」と「ログフォルダーを開く」が、ファイルメニュー直下に表示されていないことを確認する。
4. ファイルメニュー直下に「ログ」が表示されることを確認する。
5. 「ログ」にマウスを合わせるかクリックする。
6. 以下のサブメニューが表示されることを確認する。

   - ログを表示
   - ログフォルダーを開く

## ログを表示

1. 「ファイル」→「ログ」→「ログを表示」を押す。
2. チケット038で実装したログ専用ウィンドウが開くことを確認する。
3. 最新ログが表示されることを確認する。
4. 再度同じメニューを押しても、ログウィンドウが重複して増えないことを確認する。

## ログフォルダーを開く

1. 「ファイル」→「ログ」→「ログフォルダーを開く」を押す。
2. エクスプローラーで既存ログ保存先が開くことを確認する。
3. 最新ログファイルが確認できることを確認する。

## メニュー表示順

1. ファイルメニュー内の表示順を確認する。
2. お気に入り設定のインポート・エクスポートの後に「ログ」があることを確認する。
3. 「終了」が最下部にあることを確認する。
4. 区切り線が不自然に重複していないことを確認する。

## 回帰確認

- お気に入り設定のインポートが動作すること
- お気に入り設定のエクスポートが動作すること
- ログ専用ウィンドウ内の再読み込みが動作すること
- 範囲コピー、`Ctrl+A`、`Ctrl+C`、全文コピーが動作すること
- 自動更新、検索、ログフォルダー表示が動作すること
- ファイルメニューの「終了」が動作すること
- WebView2、IPC、設定画面、About画面へ影響がないこと
- Debug構成で警告0・エラー0でビルド成功すること
