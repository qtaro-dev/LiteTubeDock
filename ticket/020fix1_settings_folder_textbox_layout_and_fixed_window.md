# チケット020fix1: 設定フォルダ欄のレイアウト修正と設定画面サイズ固定

## 目的

チケット020の追加修正として、設定画面の「設定フォルダ」欄の表示崩れを修正する。

現在、基本設定画面の「設定フォルダ」テキスト欄だけ、ウィンドウ幅やレイアウト状態によって横幅の自動調整が不自然になっている。

あわせて、設定画面は固定サイズのダイアログとして扱い、ユーザーが上下左右にリサイズできないようにする。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの仕様には触れない。
- 今回は SettingsWindow のレイアウト修正のみを対象とする。
- チケット020の追加修正として扱う。

## 対象ファイル

推定対象:

- `SettingsWindow.xaml`
- `SettingsWindow.xaml.cs`
- `Views/GeneralSettingsView.xaml`
- `Views/GeneralSettingsView.xaml.cs`
- 必要に応じて設定モデル、設定サービス関連ファイル

## 現象1: 設定フォルダのテキスト欄だけ横幅調整がおかしい

### 現状

基本設定画面の「設定フォルダ」欄で、テキスト欄に以下のようなパスが表示される。

```text
E:\Dev\LiteTubeDock\settings
```

しかし、他の入力欄と比べてこのテキスト欄だけ横幅の自動調整が不自然で、ウィンドウ幅や配置によって見た目が崩れる。

### 修正内容

設定フォルダ行のレイアウトを安定させる。

期待する配置:

```text
設定フォルダ   [ E:\Dev\LiteTubeDock\settings            ] [参照] [開く]
```

要件:

- 「設定フォルダ」ラベルは左側に配置する。
- テキスト欄は中央の入力欄として自然な横幅を使う。
- 「参照」「開く」ボタンは右側に固定幅で並べる。
- テキスト欄だけが不自然に伸びたり縮んだりしないようにする。
- 他の入力項目と横位置・余白の統一感を保つ。
- `TextBox.Text` には、参照ボタンで選択したフォルダパスをそのまま表示する。
- 表示上 `settings` のような相対パスだけに戻らないようにする。

### 参照ボタンの挙動

「参照」ボタンでフォルダを選択した場合、選択したフォルダパスを設定フォルダのテキスト欄にそのまま反映する。

例:

```text
E:\Dev\LiteTubeDock\settings
```

または、ユーザーが選択した任意のフォルダパス。

内部的に相対パスを使う仕様がある場合でも、画面表示・保存値・復元値が矛盾しないようにする。

## 現象2: 設定画面を上下左右にリサイズできてしまう

### 現状

設定画面が通常ウィンドウとして上下左右にリサイズできる。

設定画面は項目数が多く、リサイズによってレイアウトが崩れやすいため、固定サイズダイアログとして扱いたい。

### 修正内容

`SettingsWindow` をユーザーが上下左右にリサイズできないようにする。

要件:

- ウィンドウ枠をドラッグしてサイズ変更できない。
- 最大化ボタンを無効化、または表示しない。
- 最小化ボタンは既存方針に合わせて維持・非表示どちらでもよいが、既存挙動を優先する。
- 設定画面内の右側コンテンツは、固定サイズ内でスクロールして表示する。
- 下部の「初期値に戻す」「キャンセル」「保存」ボタンは固定表示を維持する。

推奨:

```xml
ResizeMode="NoResize"
```

必要であれば、以下も確認する。

- `SizeToContent`
- `MinWidth` / `MinHeight`
- `MaxWidth` / `MaxHeight`
- 初期 `Width` / `Height`

## 実装時の注意

### 設定フォルダ欄

- テキスト欄の横幅を固定しすぎて、パスが極端に読みにくくならないようにする。
- ただし、ウィンドウサイズ固定後の表示範囲内で安定することを優先する。
- 「参照」「開く」ボタンが右端で切れないこと。
- 他の設定項目の配置を崩さないこと。
- 基本設定画面のスクロール挙動を壊さないこと。

### 設定画面サイズ固定

- 設定画面を固定サイズにしても、基本設定とお気に入りボタンの両方がスクロールで最後まで見られること。
- 下部固定ボタンが画面外に出ないこと。
- 高DPI環境や通常のWindows拡大率でも極端に崩れないこと。
- メインウィンドウのリサイズ挙動には影響を与えないこと。
- HelpWindow / AboutWindow のサイズ挙動には影響を与えないこと。

## 受け入れ条件（目視確認基準）

### 設定フォルダ欄の表示確認

1. LiteTube Dock を起動する。
2. 設定画面を開く。
3. 左カテゴリで「基本設定」を選択する。
4. 「設定フォルダ」欄を見る。
5. テキスト欄が他の入力欄と比べて不自然に短くなったり、長くなりすぎたりしていないことを確認する。
6. 「設定フォルダ」ラベル、テキスト欄、「参照」「開く」ボタンが横一列で自然に並んでいることを確認する。
7. 「参照」ボタンを押して任意のフォルダを選択する。
8. 選択したフォルダパスがテキスト欄にそのまま表示されることを確認する。
9. 表示が `settings` のような相対パスだけに戻らないことを確認する。
10. 「保存」を押して閉じ、再度設定画面を開いたときも保存済みのパスが表示されることを確認する。

### 設定画面サイズ固定確認

1. 設定画面の上下左右の端にマウスカーソルを合わせる。
2. ウィンドウサイズ変更用のカーソルにならない、またはドラッグしてもサイズ変更できないことを確認する。
3. 最大化ボタンが無効化、または表示されていないことを確認する。
4. 設定画面内の右側スクロールで、基本設定の下部まで表示できることを確認する。
5. 左カテゴリで「お気に入りボタン」を選択する。
6. お気に入りボタン設定一覧も、スクロールで最後まで表示できることを確認する。
7. 下部の「初期値に戻す」「キャンセル」「保存」ボタンが常に見えていることを確認する。

### 既存機能確認

- MainWindow が通常通り起動する。
- 設定画面を開閉できる。
- 基本設定とお気に入りボタンのカテゴリ切替ができる。
- 保存、キャンセル、初期値に戻すが動作する。
- ヘルプ画面、バージョン情報画面の表示に影響が出ていない。
- YouTube / Google / WebView2 関連の挙動に変更が入っていない。
