# チケット027fix2: ナビゲーションボタンを一回り大きくし、ホバー色をオレンジ系に変更する

## 目的

チケット027・027fix1で MainWindow 上部に「戻る」「進む」「再読み込み」「ホーム」のナビゲーションボタンを追加し、4ボタンのサイズとホバー表示を統一した。

現在は4ボタンの見た目は揃っているが、実際に画面で確認すると以下の改善余地がある。

- ボタンがまだ少し小さく見える
- ホバー時の灰色表示がWindows標準ボタン感に寄っている
- LiteTube Dock のロゴ・アイコン色と合わせて、薄いオレンジ系のホバー表示にしたい

ナビゲーションボタンをもう一回り大きくし、ホバー時・押下時の表示を LiteTube Dock のブランドカラーに近いオレンジ系へ変更する。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの仕様には触れない。
- YouTube広告を自動キャンセル、非表示、削除、置換、スキップする機能は実装しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。
- 今回はチケット027で追加したナビゲーションボタンの見た目調整のみを対象とする。

## 対象ファイル

推定対象:

- `MainWindow.xaml`
- 必要に応じて共通Style定義

主な対象Style:

```text
NavigationToolbarButtonStyle
```

使用中のアイコン画像:

```text
E:\Dev\LiteTubeDock\Resource\Left.png
E:\Dev\LiteTubeDock\Resource\Right.png
E:\Dev\LiteTubeDock\Resource\RELOAD.png
E:\Dev\LiteTubeDock\Resource\HOME.png
```

## 現状

チケット027fix1で以下のように統一済み。

```text
ボタンサイズ: 36x32
アイコンサイズ: 22x22
```

ただし、画面上ではまだ少し小さく見える。

また、ホバー時の色が灰色系のため、アプリ全体のロゴ色・アイコン色であるオレンジ系と統一感が弱い。

## 実装内容

### 1. ナビゲーション4ボタンをもう一回り大きくする

以下4つのボタンを、現在より少し大きくする。

- 戻る
- 進む
- 再読み込み
- ホーム

推奨サイズ:

```text
Width: 40〜44
Height: 34〜38
```

現在の `36x32` より一回り大きくし、押しやすく見やすいサイズにする。

ただし、上部ツールバー全体の高さが不自然に大きくならないようにする。

### 2. アイコン画像も少し大きくする

ボタン拡大に合わせて、アイコン画像サイズも少し大きくする。

推奨サイズ:

```text
Image Width: 24〜26
Image Height: 24〜26
```

要件:

- 4つのアイコンの見た目サイズが揃っていること。
- アイコンがボタン中央に表示されること。
- アイコンがボタンからはみ出さないこと。
- アドレスバーの横幅を極端に圧迫しないこと。

### 3. ホバー時の色を薄いオレンジ系に変更する

現在の灰色系ホバー表示を、LiteTube Dock のブランドカラーに寄せた薄いオレンジ系に変更する。

推奨色:

```text
Hover Background: #FFF1E8
Hover Border: #FF8A3D
```

または、既存テーマとの相性を見て近い薄オレンジ色に調整してよい。

### 4. 押下時の色を少し濃いオレンジ系に変更する

ボタン押下時は、ホバーより少し濃いオレンジ系にする。

推奨色:

```text
Pressed Background: #FFD8C2
Pressed Border: #FF5A1F
```

要件:

- ホバー時と押下時の違いが分かること。
- 派手すぎず、上部ツールバーに馴染むこと。
- 4ボタンすべて同じ表示になること。

### 5. 通常時・無効時の見た目は自然に維持する

通常時は、既存の白〜薄いグレー系を維持してよい。

無効時は、戻る・進むの履歴状態が分かるようにする。

要件:

- 無効時にアイコンが極端に見えなくならないこと。
- 有効/無効の違いが分かること。
- 無効時もボタンサイズ・配置がずれないこと。

### 6. 共通Styleで一括管理する

4ボタンのサイズ・ホバー色・押下色は、可能な限り `NavigationToolbarButtonStyle` で一括管理する。

要件:

- 戻る・進む・再読み込み・ホームで個別に見た目がズレないこと。
- 同じStyleを使うこと。
- 将来の微調整が1か所で済む構造にすること。

## 実装時の注意

- ボタンを大きくしても、アドレスバーが極端に狭くならないようにする。
- 「移動」「現在URLをコピー」ボタンの配置を崩さない。
- メニュー行や WebView2 表示位置を不自然にずらさない。
- ToolTip は維持する。
- 既存クリック処理・ショートカット処理を壊さない。
- アイコン画像ファイル自体は変更しなくてよい。
- XAML側の Button / Image サイズ、Style、Padding、Margin、Trigger の調整を優先する。
- YouTube / Google / WebView2 関連の処理には触れない。

## 受け入れ条件（目視確認基準）

### サイズ確認

1. LiteTube Dock を起動する。
2. MainWindow 上部を見る。
3. 戻る・進む・再読み込み・ホームの4ボタンが、チケット027fix1時点より一回り大きく表示されていることを確認する。
4. 4ボタンのサイズが揃っていることを確認する。
5. アイコンが小さすぎず、押しやすい見た目になっていることを確認する。
6. アドレスバーが極端に狭くなっていないことを確認する。

### ホバー色確認

1. 戻るボタンにマウスを乗せる。
2. 背景または枠が薄いオレンジ系になることを確認する。
3. 進むボタンにマウスを乗せる。
4. 同じ薄いオレンジ系の表示になることを確認する。
5. 再読み込みボタンにマウスを乗せる。
6. 同じ薄いオレンジ系の表示になることを確認する。
7. ホームボタンにマウスを乗せる。
8. 同じ薄いオレンジ系の表示になることを確認する。

### 押下色確認

1. 各ナビゲーションボタンを押す。
2. 押下中または押下時に、ホバーより少し濃いオレンジ系の表示になることを確認する。
3. 4ボタンで押下表示が揃っていることを確認する。

### 動作確認

1. 戻るボタンを押して、WebView2 の履歴を戻れることを確認する。
2. 進むボタンを押して、WebView2 の履歴を進めることを確認する。
3. 再読み込みボタンを押して、現在ページを再読み込みできることを確認する。
4. ホームボタンを押して、設定済みホームURLへ移動できることを確認する。
5. 各ボタンの ToolTip が表示されることを確認する。

### 既存機能確認

- アドレスバーの URL入力・貼り付け・移動が動作する。
- 「移動」ボタンが動作する。
- 「現在URLをコピー」ボタンが動作する。
- ファイルメニュー、表示メニュー、設定メニュー、ヘルプメニューが開ける。
- お気に入りボタンが動作する。
- 設定画面、ヘルプ画面、バージョン情報画面を開ける。
- YouTube / Google / WebView2 関連の挙動に変更が入っていない。

## 補足

今回の主目的は、チケット027fix1で揃えたナビゲーションボタンを、さらに使いやすく・LiteTube Dockらしい見た目に寄せることである。

特に以下を改善する。

- まだ少し小さく見える
- 灰色ホバーが標準UI感に寄りすぎている
- ロゴやアイコンのオレンジ色と統一感を出したい
