# チケット025: お気に入りボタン設定カードのスロット番号表示を見やすくする

## 目的

設定画面の「お気に入りボタン」カテゴリで、各スロット番号 `01` `02` などの表示が小さく、視認性が低い。

各お気に入りカードの左側に、スロット番号を大きく表示する縦帯エリアを追加し、どのスロットを編集しているのか分かりやすくする。

将来的には、お気に入りボタンの背景色・文字色をこの番号エリアにも反映できるようにしたいが、まずは土台となるレイアウトを実装する。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの仕様には触れない。
- 今回は SettingsWindow の「お気に入りボタン」設定カードの見た目改善のみを対象とする。
- 設定画面は固定サイズのまま扱う。
- 右側コンテンツはスクロールで表示する既存方針を維持する。

## 対象ファイル

推定対象:

- `Views/FavoriteButtonsSettingsView.xaml`
- `Views/FavoriteButtonsSettingsView.xaml.cs`
- 必要に応じてお気に入りボタン設定カード生成処理
- 必要に応じてお気に入りモデル
- 必要に応じて共通スタイル定義

## 現状

「お気に入りボタン」設定画面では、各カードの左側に `01` `02` のようなスロット番号が表示されている。

ただし、現在の表示は文字が小さく、設定項目の中に埋もれて見えやすい。

そのため、どのスロットを編集しているのか瞬時に分かりづらい。

## 実装内容

### 1. 各お気に入りカードの左側に番号表示エリアを追加する

各お気に入り設定カードの左側に、縦長の番号表示エリアを配置する。

表示イメージ:

```text
┌────┬──────────────────────────────────────┐
│    │ 表示名  [ Home                         ] [削除] [有効]
│ 01 │ URL     [ https://www.youtube.com/     ]
│    │ アイコン [                              ] [選択]
│    │ 背景色  [ #F0F0F0 ] 文字色 [ #000000 ]
└────┴──────────────────────────────────────┘
```

要件:

- 左側に縦長の帯エリアを作る。
- 帯エリアの中央付近に `01` `02` などの番号を大きめに表示する。
- 番号は2桁表示を維持する。
- 番号の視認性を上げる。
- 右側の既存入力欄レイアウトは大きく崩さない。

### 2. まずは固定デザインで実装する

初期実装では、番号表示エリアは固定デザインでよい。

推奨初期デザイン:

- 背景色: 黒または濃いグレー
- 文字色: 白
- 番号文字サイズ: 現在より大きくする
- 番号は縦帯の中央に配置
- 帯幅は広すぎず、ただし番号が読みやすい幅にする

例:

```text
背景: #111111
文字: #FFFFFF
番号: 01
```

### 3. 背景色・文字色継承の土台を作る

可能であれば、将来的に以下を反映しやすい構造にする。

- お気に入り設定の `背景色`
- お気に入り設定の `文字色`

理想:

```text
番号表示エリアの背景色 = お気に入りボタン背景色
番号表示エリアの文字色 = お気に入りボタン文字色
```

ただし、CODEXのみで完全実装が難しい場合は、以下の土台だけでよい。

- 番号表示エリアを独立した Border / Grid として作る
- 背景色と文字色を後からバインドしやすい構造にする
- 固定色指定の箇所を分かりやすくしておく
- コメントで「将来、背景色・文字色をお気に入り設定から反映する候補」と分かるようにしておく

### 4. 既存の入力操作を維持する

以下の操作に影響を出さない。

- 表示名入力
- URL入力
- アイコン選択
- 背景色入力
- 文字色入力
- 形状選択
- 角丸チェック
- 再生モード選択
- 自動再生、ミュート、ループ、リジューム
- 削除ボタン
- 有効チェック

### 5. スクロールと固定下部ボタンを維持する

- お気に入りボタン設定一覧はスクロールで最後まで見られること。
- 設定画面下部の「初期値に戻す」「キャンセル」「保存」は固定表示のままにする。
- 設定画面の固定サイズ方針を維持する。

## 実装時の注意

- 番号表示エリアを追加しても、カード全体が横にはみ出さないようにする。
- 既存の入力欄が極端に短くならないようにする。
- 各カードの高さが増えすぎないようにする。
- スロット番号はカード内の左側で目立つようにする。
- 背景色・文字色の完全な動的反映が難しい場合は、無理に複雑化しない。
- 今回は見やすい土台作りを優先する。
- 既存の保存データ形式を変更しない。
- お気に入りボタン本体の表示には影響を与えない。
- MainWindow 側のお気に入りボタン表示仕様は今回の対象外とする。

## 受け入れ条件（目視確認基準）

### 番号表示確認

1. LiteTube Dock を起動する。
2. 設定画面を開く。
3. 左カテゴリで「お気に入りボタン」を選択する。
4. 各お気に入り設定カードの左側に、縦長の番号表示エリアが表示されることを確認する。
5. `01` `02` などの番号が、以前より大きく見やすく表示されることを確認する。
6. 番号表示エリアがカードの左側に自然に収まっていることを確認する。
7. カード全体が横にはみ出していないことを確認する。

### 入力操作確認

1. 表示名を編集できることを確認する。
2. URLを編集できることを確認する。
3. アイコンの「選択」ボタンが押せることを確認する。
4. 背景色と文字色の入力欄が使えることを確認する。
5. 形状コンボボックスを変更できることを確認する。
6. 各チェックボックスを操作できることを確認する。
7. 削除ボタンが押せることを確認する。
8. 有効チェックが操作できることを確認する。

### スクロール確認

1. お気に入りボタン設定一覧をマウスホイールでスクロールできることを確認する。
2. スクロールバーで下部のカードまで移動できることを確認する。
3. 下部の「初期値に戻す」「キャンセル」「保存」ボタンが固定表示されていることを確認する。

### 既存機能確認

- 基本設定画面に影響が出ていない。
- 設定画面の固定サイズ方針が維持されている。
- 保存、キャンセル、初期値に戻すが動作する。
- MainWindow のお気に入りボタン表示が壊れていない。
- YouTube / Google / WebView2 関連の挙動に変更が入っていない。

## 補足

理想としては、番号表示エリアの背景色と文字色を、お気に入りボタン設定の背景色・文字色から反映できるとよい。

ただし、今回の主目的は、スロット番号を大きく見やすくし、カードの識別性を上げることである。

背景色・文字色の完全連動が難しい場合は、まず固定色の番号帯を作り、後から手作業または別チケットで調整できる構造にしておく。
