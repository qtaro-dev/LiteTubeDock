# チケット026: お気に入り設定カードの有効チェック位置・表示名プレビュー・太字設定を改善する

## 目的

お気に入りボタン設定画面の操作性と、MainWindow 下部のお気に入りボタン表示を改善する。

現在、各お気に入り設定カードの「有効」チェックが右端にあり、実際に使ってみると分かりづらい。

また、表示名の入力欄は長い文字列を入れられるが、MainWindow 下部のお気に入りボタンでは長い文字列が折り返されず、見切れたり読みにくくなったりする。

あわせて、お気に入りボタンの文字列を太字にできる設定を追加し、ボタン表示の見やすさを調整できるようにする。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの仕様には触れない。
- YouTube広告を自動キャンセル、非表示、削除、置換、スキップする機能は実装しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。
- 今回はお気に入りボタン設定画面と、MainWindow 下部のお気に入りボタン表示の改善のみを対象とする。

## 対象ファイル

推定対象:

- `Views/FavoriteButtonsSettingsView.xaml`
- `Views/FavoriteButtonsSettingsView.xaml.cs`
- `MainWindow.xaml`
- `MainWindow.xaml.cs`
- `Models` 配下のお気に入りボタン設定モデル
- `Services` 配下のお気に入り設定保存・読み込み処理
- 必要に応じて `bookmarks.json` の読み書き処理

## 現状の課題

### 課題1: 「有効」チェックの位置が分かりづらい

現在、各お気に入り設定カードの「有効」チェックは、表示名入力欄の右側、削除ボタン付近に配置されている。

実際に設定画面を操作すると、カード全体の有効/無効を切り替える重要項目にもかかわらず、右端にあり視認性が低い。

### 課題2: 下部ボタンの表示名が長いと見づらい

表示名入力欄には長い文字列を入れられる。

しかし MainWindow 下部のお気に入りボタンでは、長い表示名がそのまま横方向に伸びる、または途中で見切れるため、分かりづらい。

ユーザー意図:

- 表示名入力欄自体は長くてよい。
- MainWindow 下部のお気に入りボタンでは、先頭100文字程度までは表示対象にしたい。
- ボタン内では長い文字列を折り返して表示したい。

### 課題3: お気に入りボタン文字を太字にしたい

お気に入りボタンごとに、表示名を太字表示できる設定を追加したい。

用途:

- 重要なボタンを目立たせる
- 色と組み合わせて視認性を上げる
- ボタン名が短い場合に見やすくする

## 実装内容

### 1. 「有効」チェックをカード左上寄りへ移動する

各お気に入り設定カードの「有効」チェックを、現在の右端から、カード左上寄りへ移動する。

希望位置:

- スロット番号帯の右側
- 表示名ラベルより上、または表示名行の左上付近
- ユーザーがカードを見た時に、まず有効状態が分かる位置

表示イメージ:

```text
[番号帯]  [有効] 
          表示名 [ Home                         ] [削除]
          URL    [ https://www.youtube.com/     ]
```

または、レイアウト上自然であれば以下でもよい。

```text
[番号帯]  [有効]  表示名 [ Home                 ] [削除]
```

要件:

- 「有効」チェックがカード右端に埋もれないこと。
- 各カードの有効/無効状態が分かりやすいこと。
- 既存の有効/無効保存処理は維持すること。
- 既存の `x:Name` を変更せずに済む場合は維持すること。

### 2. 表示名入力欄は長めのまま維持する

設定画面上の「表示名」入力欄は、現在のように長めの文字列を入力できる状態を維持する。

要件:

- 入力欄を極端に短くしない。
- 長い表示名を入力できる。
- 表示名入力欄の最大文字数を新たに厳しく制限しない。
- ただし、MainWindow 下部ボタン表示では見やすく制御する。

### 3. MainWindow 下部のお気に入りボタン表示を折り返し対応にする

MainWindow 下部のお気に入りボタンで、表示名が長い場合に折り返して表示できるようにする。

要件:

- ボタン内テキストを折り返し表示する。
- ボタン幅を極端に広げすぎない。
- お気に入りボタン欄全体のレイアウトを壊さない。
- 先頭100文字程度までを表示対象にする。
- 100文字を超える場合は、内部表示用に省略してよい。
- 省略する場合は末尾に `…` を付けるなど、見切れていることが分かる表現にする。
- 表示名が短い場合は、従来通り自然に表示する。

推奨仕様:

```text
表示用文字列 = 表示名の先頭100文字
100文字を超える場合 = 先頭100文字 + …
```

ボタン内では `TextBlock.TextWrapping="Wrap"` 相当の折り返し表示を使う。

### 4. お気に入りボタンごとに「太字」設定を追加する

お気に入り設定カードに「太字」チェックを追加する。

配置候補:

- 文字色欄の近く
- 角丸チェックの近く
- 表示に関する設定がまとまっている場所

表示例:

```text
文字色 [ #FFFFFF ] [色プレビュー]  [太字]
```

要件:

- 各お気に入りスロットごとに太字ON/OFFを保存できる。
- MainWindow 下部のお気に入りボタン表示に反映される。
- 太字OFFの場合は通常の文字太さで表示する。
- 太字ONの場合は `FontWeight="Bold"` 相当で表示する。
- 設定画面を閉じて再度開いても太字設定が復元される。
- 既存の `bookmarks.json` に新しい項目が必要な場合は、後方互換を考慮する。

### 5. 既存データとの互換性を維持する

既存の `bookmarks.json` に太字設定がない場合でも、読み込み時にエラーにならないようにする。

推奨:

- 新規プロパティ例: `IsBold`
- 既存データに `IsBold` がない場合は `false` として扱う。
- 保存時は `IsBold` を保存してよい。
- 既存の背景色、文字色、形状、角丸、再生モード等の保存形式を壊さない。

### 6. 設定画面の番号帯プレビューとの整合性

チケット025fix1で実装した番号帯の背景色・文字色連動は維持する。

太字設定については、可能であれば番号帯の番号にも反映してよい。

ただし必須ではない。

優先順位:

1. MainWindow 下部のお気に入りボタンに太字を反映
2. 設定保存・復元
3. 余裕があれば番号帯の番号にも太字反映

## 実装時の注意

- お気に入りボタンの既存保存処理を壊さない。
- 既存の背景色・文字色・角丸・形状・再生モードなどの設定を壊さない。
- MainWindow 下部ボタンの高さが極端に増えないようにする。
- 長文折り返しによってボタン列全体が崩れないようにする。
- ボタン幅や高さは既存デザインを基準に調整する。
- 太字設定追加により、既存の `bookmarks.json` を読めなくしない。
- 有効チェック移動後も、各スロットの有効/無効が正しく保存・復元されること。
- YouTube / Google / WebView2 関連の処理には触れない。

## 受け入れ条件（目視確認基準）

### 有効チェック位置確認

1. LiteTube Dock を起動する。
2. 設定画面を開く。
3. 左カテゴリで「お気に入りボタン」を選択する。
4. 各カードの「有効」チェックが右端ではなく、カード左上寄りに表示されていることを確認する。
5. 有効/無効の状態が以前より分かりやすいことを確認する。
6. チェックON/OFFを切り替えられることを確認する。

### 有効設定保存確認

1. 任意のスロットの「有効」をOFFにする。
2. 「保存」を押す。
3. 設定画面を閉じる。
4. 再度設定画面を開く。
5. 該当スロットの「有効」がOFFのまま復元されることを確認する。
6. MainWindow 下部のお気に入りボタン表示にも有効/無効状態が反映されることを確認する。

### 表示名折り返し確認

1. 任意のお気に入りスロットの表示名に長い文字列を入力する。
2. 「保存」を押す。
3. MainWindow 下部のお気に入りボタンを見る。
4. 長い表示名が横にはみ出さず、ボタン内で折り返されることを確認する。
5. 100文字を超える文字列を設定した場合、表示用文字列が先頭100文字程度までに制限され、必要に応じて省略記号が付くことを確認する。
6. お気に入りボタン列全体のレイアウトが崩れていないことを確認する。

### 太字設定確認

1. 設定画面を開く。
2. 任意のお気に入りスロットで「太字」をONにする。
3. 「保存」を押す。
4. MainWindow 下部のお気に入りボタンの文字が太字になることを確認する。
5. 同じスロットの「太字」をOFFにする。
6. 「保存」を押す。
7. MainWindow 下部のお気に入りボタンの文字が通常の太さに戻ることを確認する。

### 太字設定保存・復元確認

1. 任意のお気に入りスロットで「太字」をONにする。
2. 「保存」を押す。
3. 設定画面を閉じる。
4. LiteTube Dock を再起動する。
5. 設定画面を開く。
6. 該当スロットの「太字」がONで復元されていることを確認する。
7. MainWindow 下部のお気に入りボタンにも太字が反映されていることを確認する。

### 既存機能確認

- 背景色・文字色を変更できる。
- 番号帯に背景色・文字色が反映される。
- 表示名、URL、アイコン、形状、角丸を変更できる。
- 再生モード、自動再生、ミュート、ループ、リジュームを操作できる。
- 削除ボタンが動作する。
- お気に入りボタン設定一覧をスクロールできる。
- 下部の「初期値に戻す」「キャンセル」「保存」ボタンが固定表示される。
- MainWindow の Home / Reload / Back / Forward / アドレスバー操作が壊れていない。
- YouTube / Google / WebView2 関連の挙動に変更が入っていない。

## 補足

ユーザー意図:

- 「有効」はカード右端ではなく、スロット番号や表示名の近くに置きたい。
- 表示名入力欄は長くてもよい。
- MainWindow 下部のお気に入りボタンでは、長い表示名でも折り返して読めるようにしたい。
- お気に入りボタンごとに太字指定を付けたい。

今回の主目的は、お気に入りボタン設定画面と下部ボタン表示の実用性を上げることである。
