# タスク名

フルスクリーン表示切り替え追加

# 目的

LiteTube Dock を動画視聴用に使いやすくするため、通常表示とフルスクリーン表示を切り替えられるようにする。

# 実装内容（具体的変更指示）

## 1. Alt + Enterでフルスクリーン切り替え

- `Alt + Enter` で通常表示とフルスクリーン表示を切り替える
- フルスクリーン時は画面全体にアプリを表示する
- もう一度 `Alt + Enter` を押すと元のウィンドウ状態へ戻す

## 2. Escでフルスクリーン解除

- フルスクリーン中に `Esc` を押すと通常表示へ戻す
- 通常表示中に `Esc` を押した場合は何もしない

## 3. フルスクリーン中のUI表示

初期実装では以下の仕様とする。

- 上部メニューは非表示
- 下部お気に入りボタン列は非表示
- ステータスバーは非表示
- `PlayerWebView` を最大表示する

## 4. 元の状態の復元

フルスクリーン解除後は以下を復元する。

- ウィンドウ位置
- ウィンドウサイズ
- `WindowStyle`
- `WindowState`
- `ResizeMode`
- メニュー、お気に入りボタン、ステータスバーの表示状態

## 5. 設定保存

フルスクリーン状態そのものは終了時に保存しない。

アプリを終了して再起動した場合は通常表示で起動すること。

# 受け入れ条件（目視確認基準）

- `dotnet build` でビルドエラーがない
- `Alt + Enter` でフルスクリーンになる
- フルスクリーン時にWebView2領域が広がる
- フルスクリーン時にメニュー、ボタン列、ステータスバーが非表示になる
- もう一度 `Alt + Enter` で通常表示に戻る
- `Esc` でフルスクリーン解除できる
- 通常表示に戻った時、元のレイアウトが崩れない
- フルスクリーン状態で終了しても、次回起動時は通常表示になる
