# タスク名

チケット012fix3 バージョン情報ウィンドウを1画面表示へ再調整

# 目的

チケット012fix2で `バージョン情報` ウィンドウ本文を `ScrollViewer` 化したが、現在は右側にスクロールバーが表示され、本文下部をスクロールしないと全文を確認できない。

バージョン情報は短い内容であり、スクロールして読む画面ではなく、1画面内に全文が自然に収まる方が分かりやすい。

そのため、`AboutWindow` の外枠サイズと本文レイアウトを再調整し、スクロールバーを出さずに、以下の情報が1画面内で読めるようにする。

- アプリ名
- バージョン
- 概要
- 使用技術
- 開発者
- 開発支援
- セキュリティ方針
- 閉じるボタン

# 対象ファイル（推定可）

- `AboutWindow.xaml`
- `AboutWindow.xaml.cs`
- `README.md`

必要に応じて、`Constants/AppConstants.cs` などの文言定数も確認してよい。

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- MainWindow、SettingsWindow、HelpWindow、既存機能を壊さないこと。

## 2. AboutWindowを1画面表示前提へ戻す

`AboutWindow.xaml` の本文がスクロール前提になっている場合、スクロールバーが出ないレイアウトへ戻す。

方針:

- AboutWindowの外枠サイズを広げる
- 本文全体が1画面に入るように余白と行間を調整する
- 右側の縦スクロールバーが表示されないようにする
- セキュリティ方針の2行目も最初から見えるようにする

## 3. AboutWindowの初期サイズを拡張する

AboutWindowの初期サイズを、本文全体が見える程度に拡張する。

推奨サイズ:

```text
Width: 560
Height: 560
```

または、画面上で自然に見える同等以上のサイズにする。

重要:

- 現在のサイズでは本文下部が切れるため、十分な高さを確保すること
- `閉じる` ボタンも下部に見えること
- 1920x1080環境で自然なサイズにすること

## 4. ScrollViewerを使わない、または表示されないようにする

チケット012fix2で追加した `ScrollViewer` がある場合は、以下のいずれかにする。

推奨:

- `ScrollViewer` を削除し、通常の `Grid` / `StackPanel` で1画面表示にする

または:

- `ScrollViewer` を残す場合でも、通常表示ではスクロールバーが出ないサイズにする

ただし、今回の目的は「スクロールさせず1画面に収める」なので、可能なら `ScrollViewer` なしの構成にすること。

## 5. 本文の折り返しは維持する

スクロールをなくしても、本文の右端が切れないようにする。

各説明文 `TextBlock` には、必要に応じて以下を設定する。

```xml
TextWrapping="Wrap"
TextTrimming="None"
HorizontalAlignment="Stretch"
```

横に長い文言は1行に詰めず、自然に折り返すか、明示的に2行へ分けること。

## 6. セキュリティ方針の表示を確実に収める

セキュリティ方針は必ず1画面内に表示する。

推奨表示:

```text
セキュリティ方針
Google ID、パスワード、認証トークンは保存しません。
YouTubeログイン状態はWebView2標準のCookie/session管理に任せます。
```

上記3行が、スクロールなしで確認できること。

## 7. 余白と行間を調整する

現在の見た目では、本文下部が不足している。

必要に応じて、以下を調整する。

- セクション間の `Margin`
- 各TextBlockの行間
- 下部ボタンエリアとの余白
- Window全体のPadding

ただし、詰め込みすぎて読みにくくしないこと。

## 8. 閉じるボタンの配置を維持する

`閉じる` ボタンは下部に表示する。

仕様:

- `閉じる` ボタンが隠れない
- 右下配置、または現在の配置を維持
- 既存の `CloseAboutButton` がある場合は維持する
- `閉じる` ボタンでウィンドウを閉じられること

## 9. 開発者情報は維持する

以下の表示は維持する。

```text
開発者: Qtaro
開発支援: GPT / CODEX
```

これらが見切れず表示されること。

## 10. README更新

READMEに変更内容を追記する必要は基本的にない。

ただし、READMEにバージョン情報画面の説明がある場合は、表示と矛盾しないように確認すること。

## 11. 実装しないこと

今回のタスクでは以下を実装しない。

- バージョン情報本文の大幅な内容変更
- ライセンス一覧画面
- 外部リンク追加
- オンラインアップデート確認
- 多言語対応
- ヘルプ本文の全面改稿
- バージョン番号自動取得
- アプリ署名情報表示
- Googleログイン自動化
- YouTube UI改変
