# チケット024: アドレスバーの選択・貼り付け・移動処理を改善する

## 目的

MainWindow 上部のアドレスバーについて、URL入力・貼り付け・移動操作を使いやすくし、Enterキーと「移動」ボタンで同じ遷移処理が実行されるようにする。

現在、YouTube URLをアドレスバーへ貼り付けようとしても貼り付けできない状態がある。

また、URLを入力して Enter を押すと遷移できるが、「移動」ボタンを押しても遷移しないケースがある。

これらを修正し、アドレスバーを通常のURL入力欄として自然に使えるようにする。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの仕様には触れない。
- YouTube広告を自動キャンセル、非表示、削除、置換、スキップする機能は実装しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。
- 今回は MainWindow のアドレスバー操作改善のみを対象とする。

## 対象ファイル

推定対象:

- `MainWindow.xaml`
- `MainWindow.xaml.cs`
- アドレスバー遷移処理を持つ関連ファイル
- 外部遷移確認処理を持つ関連ファイル
- 必要に応じて URL 判定ユーティリティ

## 現状の問題

### 問題1: アドレスバーへURLを貼り付けられない

現在、アドレスバーへ YouTube URL を貼り付けようとしても、貼り付け操作ができない。

確認したい操作例:

```text
https://www.youtube.com/watch?v=xxxxxxxxxxx
```

このようなURLをコピーして、アドレスバーに貼り付けできるようにする。

### 問題2: アドレスバークリック時に既存URLを選択しづらい

アドレスバーに現在URLが表示されている状態で、新しいURLを入れようとすると、既存URLを手動で削除・選択する必要があり操作しづらい。

### 問題3: 「移動」ボタンで遷移しない

アドレスバーにURLを入力または貼り付けた後、Enterキーを押すと遷移するが、「移動」ボタンを押しても遷移しないケースがある。

Enterキーと「移動」ボタンで同じ処理を呼ぶようにする。

### 問題4: YouTube以外のURL移動時の確認処理を統一したい

アドレスバーから YouTube 以外のURLへ移動しようとした場合は、既存の外部遷移確認と同じ考え方で、遷移してよいか確認する。

## 実装内容

### 1. アドレスバーへの貼り付けを有効にする

アドレスバーの TextBox で、通常の貼り付け操作ができるようにする。

対応したい操作:

- 右クリックメニューから貼り付け
- `Ctrl + V`
- 可能であれば `Shift + Insert`

確認対象:

- `TextBox` が読み取り専用になっていないか
- `PreviewKeyDown` / `PreviewTextInput` などで貼り付け操作を握りつぶしていないか
- コンテキストメニューが無効化されていないか
- `CommandBindings` で貼り付けコマンドが無効化されていないか
- 独自イベント処理で `Handled = true` にしすぎていないか

### 2. アドレスバークリック時に全選択しやすくする

アドレスバーをクリックしたとき、現在URLを全選択して、新しいURLをすぐ入力または貼り付けできるようにする。

期待する挙動:

- アドレスバーにフォーカスがない状態でクリックする
- 現在表示されているURLが全選択される
- そのまま文字入力または貼り付けすると、既存URLが置き換わる

注意:

- すでにフォーカスがある状態でクリックした場合は、通常のカーソル移動を妨げすぎないこと。
- マウスドラッグで部分選択したい操作を完全に壊さないこと。
- 実装が複雑になる場合は、まずは「初回フォーカス時に全選択」を優先する。

### 3. クリップボードにURLがある場合に貼り付けやすくする

クリップボードにURL文字列がある状態で、アドレスバーへ貼り付けできるようにする。

必須要件:

- クリップボードのURLをユーザー操作で貼り付けできること。
- 勝手にクリップボードを読み取って自動入力しすぎないこと。
- クリックしただけで自動貼り付けする挙動は不要。

補足:

- ユーザーの意図は「URLがクリップボードにある時、アドレスバーへ貼り付けられること」。
- 自動貼り付け機能ではなく、通常の貼り付け操作が正しく動くことを優先する。

### 4. Enterキーと「移動」ボタンの遷移処理を共通化する

Enterキー押下時と「移動」ボタンクリック時で、同じ遷移処理を実行する。

推奨:

```text
NavigateFromAddressBar()
```

のような共通メソッドを作り、以下の両方から呼び出す。

- アドレスバーで Enter キー押下
- 「移動」ボタンクリック

共通処理内で行うこと:

- アドレスバーの入力値を取得する
- 前後空白を除去する
- `http://` または `https://` がない場合は `https://` を補完する
- URLとして妥当か確認する
- YouTube系URLかどうか確認する
- 必要に応じて外部遷移確認を行う
- 許可された場合だけ WebView2 を遷移させる

### 5. YouTube以外のURLでは確認ダイアログを出す

アドレスバーに入力されたURLが YouTube 系URLではない場合、遷移前に確認ダイアログを表示する。

確認対象例:

- `https://www.google.com/`
- `https://example.com/`
- `https://github.com/`

確認不要の例:

- `https://www.youtube.com/`
- `https://youtube.com/`
- `https://m.youtube.com/`
- `https://youtu.be/xxxx`
- 必要に応じて既存のYouTube判定ロジックに合わせる

確認文言は既存の外部遷移確認と統一する。

既存文言:

```text
動画ページ以外へ移動しようとしています。
遷移してよろしいですか？
```

要件:

- `いいえ` をデフォルト選択にする。
- `いいえ` の場合は遷移しない。
- `はい` の場合のみ遷移する。
- 既存の「動画ページ以外への遷移を確認する」設定がOFFの場合は、既存仕様に合わせて確認を省略する。

### 6. YouTube URLでは通常通り遷移する

アドレスバーに YouTube URL が入力・貼り付けされている場合は、確認なしで遷移する。

例:

```text
https://www.youtube.com/watch?v=xxxxxxxxxxx
https://youtu.be/xxxxxxxxxxx
https://www.youtube.com/live/xxxxxxxxxxx
```

### 7. アドレスバー表示同期は維持する

WebView2内でYouTube内遷移した場合、現在URLがアドレスバーへ同期される既存仕様は維持する。

ただし、ユーザーがアドレスバー編集中の場合に、編集中の文字列が不意に上書きされないよう注意する。

## 実装時の注意

- アドレスバー TextBox の通常操作を壊さない。
- コピー、切り取り、貼り付け、全選択などの標準ショートカットを使えるようにする。
- Enterキー処理で `Handled = true` にする場合でも、貼り付け操作まで妨げない。
- 「移動」ボタンだけ別処理にならないようにする。
- 外部遷移確認は既存ロジックをできるだけ再利用する。
- YouTube広告対策・広告スキップ・DOM操作のような処理は追加しない。
- Home / Reload / お気に入りボタンなど、アプリ側の明示操作に対する既存の確認スキップ仕様を壊さない。
- WebView2の通常ナビゲーション処理に余計な副作用を出さない。

## 受け入れ条件（目視確認基準）

### 貼り付け確認

1. YouTube動画URLをクリップボードにコピーする。
2. LiteTube Dock を起動する。
3. アドレスバーをクリックする。
4. 現在URLが全選択されることを確認する。
5. `Ctrl + V` でURLを貼り付けできることを確認する。
6. 右クリックメニューからも貼り付けできることを確認する。
7. 貼り付けたURLがアドレスバーに表示されることを確認する。

### Enter遷移確認

1. アドレスバーに YouTube URL を貼り付ける。
2. Enterキーを押す。
3. WebView2 がそのURLへ遷移することを確認する。

### 移動ボタン遷移確認

1. アドレスバーに YouTube URL を貼り付ける。
2. 「移動」ボタンを押す。
3. Enterキーと同じように WebView2 がそのURLへ遷移することを確認する。

### https補完確認

1. アドレスバーに以下のように入力する。

```text
www.youtube.com
```

2. Enterキー、または「移動」ボタンを押す。
3. `https://www.youtube.com` として遷移できることを確認する。

### YouTube以外URLの確認ダイアログ

1. アドレスバーに以下のようなURLを入力する。

```text
https://example.com/
```

2. Enterキー、または「移動」ボタンを押す。
3. 外部遷移確認ダイアログが表示されることを確認する。
4. `いいえ` がデフォルト選択であることを確認する。
5. `いいえ` を選ぶと遷移しないことを確認する。
6. 再度同じURLで操作し、`はい` を選ぶと遷移することを確認する。

### 既存機能確認

- Home ボタンでホームURLへ移動できる。
- Reload ボタンで再読み込みできる。
- Back / Forward が動作する。
- 現在URLコピーが動作する。
- YouTube内遷移時にアドレスバーへ現在URLが同期される。
- お気に入りボタンからの遷移が動作する。
- 設定画面、ヘルプ画面、バージョン情報画面を開ける。
- YouTube / Google ログイン、広告、DOM操作まわりの仕様変更が入っていない。

## 補足

このチケットの主目的は、アドレスバーを「普通のURL入力欄」として扱えるようにすることである。

特に、以下は必ず修正対象とする。

- URLを貼り付けられない
- 「移動」ボタンで遷移しない
- YouTube以外のURLへ移動する時の確認処理が統一されていない

一方で、クリックしただけでクリップボード内容を自動貼り付けするような挙動は不要とする。
