# LiteTubeDock お気に入り背景画像の中央基準拡大縮小を修正

## 対象プロジェクト

`E:\Dev\LiteTubeDock`

※ `E:\Dev\LiteTubeDockControl` は変更しないこと。

## 目的

お気に入りボタンの背景画像が、現在は中央付近へ細く表示され、文字列との重なり方も不自然になっている。

登録画像の中心を基準点としてボタン中心へ配置し、ボタン全体を埋めるように拡大縮小する。

画像全体を完全に表示することより、ボタン領域を背景画像で自然に満たすことを優先する。上下左右の一部が切れることは許容する。

## 現在の問題

- 背景画像がボタン全面へ広がらない
- 画像が中央の細い領域へ表示される
- 表示名によって画像領域が押し縮められている
- 画像と文字列が別レイアウト領域として扱われている
- ボタン中心と画像中心が一致していない

## 期待する表示

### 基本方針

- 登録画像の中心を基準点とする
- 画像の中心をボタンの中心へ一致させる
- 縦横比を維持する
- ボタン領域全体を埋めるまで拡大または縮小する
- ボタン外へはみ出した部分は切り取る
- 上下左右の一部が切れてもよい
- 表示名は画像の前面へ重ねる
- 文字列によって画像サイズや配置が変わらない

概念的には以下。

```text
Button
└─ Grid（ボタン全面）
   ├─ Image（中央基準・全面背景）
   └─ TextBlock（中央・最前面）
```

## 実装内容

### 1. ボタン内容を全面Stretchにする

お気に入りボタンへ以下を適用する。

- `HorizontalContentAlignment="Stretch"`
- `VerticalContentAlignment="Stretch"`
- 内部Paddingを必要最小限または0
- `ClipToBounds="True"`

ボタン内部のGridがボタン全面を使用すること。

### 2. 背景画像を中央基準で表示する

Imageは以下の挙動にする。

- `HorizontalAlignment="Stretch"`
- `VerticalAlignment="Stretch"`
- `Stretch="UniformToFill"`
- `StretchDirection="Both"`
- 画像中心をボタン中心へ合わせる
- Width / Heightを固定しない
- Marginで位置調整しない
- TextBlockのサイズに影響されない

WPFの標準レイアウトで不足する場合は、中央クロップが保証されるテンプレートまたはViewbox相当の構成にする。

### 3. クロップ方針

画像全体がボタン比率と一致しない場合は、ボタン領域を埋めるために余剰部分を切り取る。

許容例:

- 横長画像を正方形ボタンへ表示する場合
  - 左右が切れてよい
- 縦長画像を横長ボタンへ表示する場合
  - 上下が切れてよい

ただし、常に画像中央を基準に切り取ること。

左上基準や右下基準で切り取らないこと。

### 4. 表示名の重ね表示

表示名は背景画像とは別レイヤーとして、常に前面へ表示する。

- 中央揃え
- 既存の文字色を使用
- 太字設定を維持
- 折り返し対応
- 画像領域を押し縮めない
- 文字列の長さで画像配置が変わらない
- ボタン外へはみ出さない

必要に応じて `Panel.ZIndex` を明示する。

### 5. 背景画像未設定時

背景画像が未設定の場合は、従来どおり以下を使用する。

- 背景色
- 文字色
- 表示名

画像設定あり / なしでボタンサイズや文字位置が変わらないこと。

### 6. 既存画像登録制限を維持

前チケットで追加した以下を維持する。

- PNG / JPEG / JPG
- 最大1024 × 1024px
- 最大2MB
- 破損画像の拒否
- 登録失敗時に既存設定を壊さない

今回の修正で検証処理を削除・緩和しないこと。

### 7. 画像読み込みと描画

画像表示時に以下を確認する。

- 元画像の縦横比を維持
- ファイルロックを残さない
- 不要な再読込を避ける
- 複数ボタンで著しく重くならない
- 画像変更後に古い画像が表示され続けない
- UIスレッドを長時間ブロックしない

### 8. 設定画面プレビュー

設定画面に背景画像のプレビューがある場合は、メイン画面と同じ中央基準・UniformToFillで表示する。

設定画面と実際のボタンで見え方が大きく異ならないこと。

## 変更しないもの

- 背景画像の登録上限
- 表示名
- 背景色
- 文字色
- 太字
- 有効 / 無効
- スタート位置
- 自動再生
- ミュート
- ループ
- お気に入り保存・削除
- インポート・エクスポート
- LiteTubeDockControl側のコード

## バージョン

今回はバージョン番号を変更しないこと。

`Version`、`AssemblyVersion`、`FileVersion`、`InformationalVersion` は現状維持とする。

## 受け入れ条件

1. 背景画像がボタン全面を埋める
2. 画像中心とボタン中心が一致する
3. 縦横比が維持される
4. ボタン比率に合わない部分は中央基準で切り取られる
5. 画像全体表示より、ボタン全面を埋めることが優先される
6. 文字列が画像の前面へ重なる
7. 文字列によって画像領域が押し縮められない
8. 背景画像が中央の細い領域へ表示されない
9. 画像がボタン外へはみ出して表示されない
10. 画像未設定時は背景色表示になる
11. 設定画面プレビューと実ボタンの見え方が一致する
12. 1024 × 1024px・2MB制限が維持される
13. 画像読み込みでファイルロックが残らない
14. 複数ボタン表示で著しく重くならない
15. Debug / Releaseビルドが警告0・エラー0で成功する
16. LiteTubeDockControl側に変更が入っていない
17. バージョン番号が変更されていない

## 確認手順

### 正方形画像

1. 正方形画像を背景画像として登録する
2. 保存する
3. 画像中心がボタン中心へ表示されることを確認する
4. 表示名が画像の前面へ重なることを確認する

### 横長画像

1. 横長画像を背景画像として登録する
2. 保存する
3. ボタン全面が画像で埋まることを確認する
4. 左右が中央基準で均等に切り取られることを確認する

### 縦長画像

1. 縦長画像を背景画像として登録する
2. 保存する
3. ボタン全面が画像で埋まることを確認する
4. 上下が中央基準で切り取られることを確認する

### 長い表示名

1. 長い表示名を設定する
2. 背景画像付きボタンを表示する
3. 文字列が折り返されることを確認する
4. 文字列によって画像サイズや中心位置が変わらないことを確認する

### 画像未設定

1. 背景画像を解除する
2. 保存する
3. 背景色と表示名だけで従来どおり表示されることを確認する
