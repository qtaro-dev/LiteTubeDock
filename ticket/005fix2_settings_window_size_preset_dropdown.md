# タスク名

チケット005fix2 設定画面にウィンドウサイズプリセットのドロップダウンを追加

# 目的

チケット005/005fix1でウィンドウサイズ関連機能を追加したが、設定画面側では `ウィンドウ幅` / `ウィンドウ高さ` の数値入力欄のみで、ユーザーがサイズプリセットを選びにくい状態になっている。

設定画面の基本設定にウィンドウサイズプリセットのドロップダウンを追加し、ユーザーが以下のような定型サイズを簡単に選べるようにする。

- 800x600
- 960x540
- 1280x720
- 1600x900
- 1920x1080
- カスタム

# 実装内容（具体的変更指示）

## 1. 作業開始前の確認

- 必ず `AGENT.md` を読むこと。
- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとすること。
- `E:\Dev\LiteTubeDock` の外側にあるファイルやフォルダは一切編集しないこと。
- 既存UIの `x:Name` は原則変更しないこと。
- 既存のMainWindow、SettingsWindowのレイアウトを全面的に作り直さないこと。

## 2. 設定画面にウィンドウサイズプリセットを追加する

`SettingsWindow.xaml` の基本設定画面に、以下の項目を追加する。

```text
ウィンドウサイズ
[ 1280x720 ▼ ]

ウィンドウ幅
[ 1280 ]

ウィンドウ高さ
[ 720 ]
```

推奨 `x:Name`:

- `WindowSizePresetComboBox`
- `WindowWidthTextBox`
- `WindowHeightTextBox`

既に `WindowWidthTextBox` / `WindowHeightTextBox` が存在する場合は、その名前を維持して利用すること。

## 3. ドロップダウン候補

`WindowSizePresetComboBox` には以下を表示する。

- `現在のサイズ`
- `800x600`
- `960x540`
- `1280x720`
- `1600x900`
- `1920x1080`
- `カスタム`

## 4. プリセット選択時の動作

`WindowSizePresetComboBox` でプリセットを選択したら、`WindowWidthTextBox` と `WindowHeightTextBox` に対応する数値を自動反映する。

例:

- `800x600` 選択時
  - `WindowWidthTextBox` = `800`
  - `WindowHeightTextBox` = `600`

- `1280x720` 選択時
  - `WindowWidthTextBox` = `1280`
  - `WindowHeightTextBox` = `720`

- `1920x1080` 選択時
  - `WindowWidthTextBox` = `1920`
  - `WindowHeightTextBox` = `1080`

## 5. カスタム選択時の動作

`カスタム` を選択した場合は、`WindowWidthTextBox` / `WindowHeightTextBox` をユーザーが手入力できるようにする。

仕様:

- `カスタム` 選択時は幅・高さ欄を編集可能
- プリセット選択時も編集可能にしてよいが、手入力変更後は `カスタム` 扱いにすることが望ましい
- 実装が複雑になる場合、プリセット選択後に幅・高さを手入力で変更できるだけでもよい

## 6. 保存処理

保存ボタン押下時に、選択中のプリセットまたは幅・高さを `settings.json` へ保存する。

推奨項目:

```json
{
  "windowSizePreset": "1280x720",
  "window": {
    "width": 1280,
    "height": 720
  }
}
```

すでに `settings.json` に幅・高さ保存処理がある場合は、それを壊さずに拡張すること。

`windowSizePreset` の保存が難しい場合でも、最低限 `window.width` / `window.height` が正しく保存されること。

## 7. 入力値チェック

保存時に以下を確認する。

- 幅・高さが数値であること
- 幅が最小値未満ではないこと
- 高さが最小値未満ではないこと
- 極端に大きすぎる値でクラッシュしないこと

推奨範囲:

- 最小幅: `640`
- 最小高さ: `360`
- 最大幅: `3840`
- 最大高さ: `2160`

不正値の場合は以下のいずれかで安全に処理する。

- エラーメッセージを表示して保存しない
- 既定値へ戻す
- 最小値/最大値に丸める

## 8. MainWindowへの反映

設定画面で保存後、MainWindow側にもサイズ設定を反映する。

期待動作:

- 設定画面で `960x540` を選択して保存
- MainWindowが `960x540` 相当へ変更される
- アプリ再起動後もそのサイズで復元される

フルスクリーン中に保存した場合は、既存のフルスクリーン処理と競合しない安全な方式を選ぶこと。

## 9. 表示メニューのプリセットとの整合性

チケット005fix1で追加済みの表示メニュー側サイズプリセットと、設定画面側のプリセット内容を一致させること。

表示メニュー側に以下が存在する場合:

- `800x600`
- `960x540`
- `1280x720`
- `1600x900`
- `1920x1080`

設定画面側にも同じ候補を表示すること。

## 10. README更新

READMEに以下を追記する。

- 設定画面の基本設定からウィンドウサイズプリセットを選択できること
- 選択可能なプリセット一覧
- カスタムサイズでは幅・高さを手入力できること
- 設定保存後、MainWindowと次回起動時のウィンドウサイズに反映されること

- `設定` → `設定を開く` で設定画面が開く
- 左側の `基本設定` を押すと基本設定パネルが表示される
- 基本設定内に `ウィンドウサイズ` のドロップダウンが表示される

  - `800x600`
  - `960x540`
  - `1280x720`
  - `1600x900`
  - `1920x1080`
  - `カスタム`
- `ウィンドウ幅` / `ウィンドウ高さ` の入力欄が短めで見やすい

- `800x600` を選ぶと、幅が `800`、高さが `600` になる

## カスタム確認

- `カスタム` を選択して幅・高さを手入力できる
- 保存後、入力したサイズがMainWindowへ反映される
