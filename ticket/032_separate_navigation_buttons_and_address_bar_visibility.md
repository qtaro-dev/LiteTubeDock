# チケット032: ナビゲーションボタンとアドレスバーの表示切替を分離する

## 目的

現在、`表示` → `アドレスバーを表示` をOFFにすると、アドレスバーだけでなく、戻る・進む・再読み込み・ホームのナビゲーションボタンも一緒に非表示になってしまう。

ナビゲーションボタンとアドレスバーは役割が異なるため、表示・非表示を別々に制御できるようにする。

あわせて、片方だけ表示した場合でも左寄せで自然に見えるよう、上部ツールバーのレイアウトを調整する。

## 前提

- 作業対象は `E:\Dev\LiteTubeDock` 配下のみとする。
- `E:\Dev\backup_LiteTubeDock` は編集しない。
- AGENT.md が存在する場合は、その内容を最優先で確認・遵守する。
- 既存設計、既存テーマ、既存ライブラリ構成を壊さない。
- 既存 `x:Name` は原則維持する。
- チケット027/027fix1/027fix2で追加・調整したナビゲーションボタンの見た目と動作を壊さない。
- チケット024で修正したアドレスバーの貼り付け・移動処理を壊さない。
- YouTube / Google のログイン、認証情報、広告、DOM操作、WebView2まわりの処理仕様には触れない。
- YouTube広告を自動キャンセル、非表示、削除、置換、スキップする機能は実装しない。
- DOM操作、自動クリック、YouTube内部API呼び出しは行わない。

## 対象ファイル

推定対象:

- `MainWindow.xaml`
- `MainWindow.xaml.cs`

- 必要に応じてヘルプ本文

## 現状の課題

`表示` → `アドレスバーを表示` をOFFにすると、以下がまとめて非表示になる。

- アドレスバー
- 移動ボタン
- 現在URLをコピー
- 戻る
- 進む
- 再読み込み
- ホーム

しかし、ユーザーとしては、以下のように分けて使いたい。

- ナビゲーションボタンだけ表示したい
- アドレスバーだけ表示したい
- 両方表示したい
- 両方非表示にしたい

## 実装内容

### 1. ナビゲーションボタンとアドレスバーの表示制御を分離する

上部ツールバーを、少なくとも以下の2つの表示単位に分ける。

#### ナビゲーションボタン部分

対象:

- 戻る
- 進む
- 再読み込み
- ホーム

#### アドレスバー部分

対象:

- URL入力欄
- 移動ボタン
- 現在URLをコピー

`アドレスバーを表示` のON/OFFでは、アドレスバー部分だけを制御する。

ナビゲーションボタン部分は、別の表示制御で扱う。

### 2. 表示メニューにナビゲーションボタン表示切替を追加する

`表示` メニューに、ナビゲーションボタン表示切替項目を追加する。

推奨表示名:

```text
ナビゲーションボタンを表示
```

または短くする場合:

```text
操作ボタンを表示
```

要件:

- チェックONで、戻る・進む・再読み込み・ホームを表示する。
- チェックOFFで、戻る・進む・再読み込み・ホームを非表示にする。
- 既存の `アドレスバーを表示` とは独立して動作する。
- 設定を保存し、次回起動時にも復元する。
- 初期値はONを推奨する。

### 3. 既存の「アドレスバーを表示」はアドレスバー部分だけを制御する

既存メニュー項目:

```text
アドレスバーを表示
```

このON/OFFで制御する対象は以下に限定する。

- URL入力欄
- 移動ボタン
- 現在URLをコピー

戻る・進む・再読み込み・ホームは、この項目では非表示にしない。

### 4. 表示状態ごとのレイアウトを調整する

以下4パターンで自然に表示されるようにする。

#### パターンA: ナビゲーションボタンON / アドレスバーON

通常状態。

期待表示:

```text
[戻る][進む][再読み込み][ホーム] [アドレスバー] [移動] [現在URLをコピー]
```

#### パターンB: ナビゲーションボタンOFF / アドレスバーON

ナビゲーションボタンを非表示にした場合。

期待表示:

```text
[アドレスバー] [移動] [現在URLをコピー]
```

要件:

- アドレスバー部分を左寄せにする。
- ナビゲーションボタンが消えた分、左側に不自然な空白を残さない。
- アドレスバーは可能な範囲で横幅を広く使う。

#### パターンC: ナビゲーションボタンON / アドレスバーOFF

アドレスバーを非表示にした場合。

期待表示:

```text
[戻る][進む][再読み込み][ホーム]
```

要件:

- ナビゲーションボタンを左寄せにする。
- アドレスバーが消えた場所に不自然な空白を残さない。
- 移動ボタン・現在URLコピーも非表示にする。

#### パターンD: ナビゲーションボタンOFF / アドレスバーOFF

両方非表示。

期待:

- 上部ツールバー行を完全に隠す、または高さを最小にする。
- WebView表示領域に不自然な空白が残らないようにする。
- メニュー行はそのまま表示する。

### 5. 設定保存・復元に対応する

ナビゲーションボタン表示状態を設定として保存する。

例:

```text
ShowNavigationButtons = true / false
```

要件:

- 既存設定ファイルにこの項目がない場合は `true` として扱う。
- アドレスバー表示状態とは別に保存する。
- 次回起動時に、前回の表示状態が復元される。
- 既存設定ファイルとの互換性を壊さない。

### 6. ヘルプの必要箇所を更新する

ヘルプ内に表示メニューの説明がある場合は、表示切替の説明を更新する。

追記例:

```text
表示メニューから、アドレスバーとナビゲーションボタンの表示/非表示を個別に切り替えられます。
```

ただし、ヘルプ本文の大規模変更は不要。

## 実装時の注意

- 既存のナビゲーションボタンのクリック処理を壊さない。
- 戻る・進む・再読み込み・ホームのToolTipを維持する。
- アドレスバーの貼り付け・Enter移動・移動ボタン処理を壊さない。
- 現在URLコピー処理を壊さない。
- `Visibility.Collapsed` を使うなどして、非表示時に不要な空白が残らないようにする。
- Grid / StackPanel / DockPanel のどれを使う場合でも、4パターンの表示が自然になるようにする。
- 既存の `アドレスバーを表示` 設定の意味を変えすぎない。
- 新規設定項目を追加する場合、既存 `settings.json` を読めなくしない。
- YouTube / Google / WebView2 関連の処理には触れない。

## 受け入れ条件（目視確認基準）

### TC-01: 両方ONの通常表示

1. LiteTube Dock を起動する。
2. `表示` メニューで `ナビゲーションボタンを表示` をONにする。
3. `アドレスバーを表示` をONにする。
4. 上部に以下が左から自然に並ぶことを確認する。

```text
戻る / 進む / 再読み込み / ホーム / アドレスバー / 移動 / 現在URLをコピー
```

### TC-02: ナビゲーションボタンOFF / アドレスバーON

1. `表示` → `ナビゲーションボタンを表示` をOFFにする。
2. `表示` → `アドレスバーを表示` をONにする。
3. 戻る・進む・再読み込み・ホームが非表示になることを確認する。
4. アドレスバー、移動、現在URLをコピーは表示されることを確認する。
5. アドレスバー部分が左寄せになることを確認する。
6. 左側にナビゲーションボタン分の空白が残らないことを確認する。

### TC-03: ナビゲーションボタンON / アドレスバーOFF

1. `表示` → `ナビゲーションボタンを表示` をONにする。
2. `表示` → `アドレスバーを表示` をOFFにする。
3. 戻る・進む・再読み込み・ホームが表示されることを確認する。
4. アドレスバー、移動、現在URLをコピーが非表示になることを確認する。
5. ナビゲーションボタンが左寄せになることを確認する。
6. アドレスバー分の空白が残らないことを確認する。

### TC-04: 両方OFF

1. `ナビゲーションボタンを表示` をOFFにする。
2. `アドレスバーを表示` をOFFにする。
3. 上部ツールバー行が非表示、または高さ最小になることを確認する。
4. WebView表示領域に不自然な余白が残らないことを確認する。
5. メニュー行は表示されたままであることを確認する。

### TC-05: 設定保存・復元

1. `ナビゲーションボタンを表示` をOFFにする。
2. `アドレスバーを表示` をONにする。
3. アプリを終了する。
4. アプリを再起動する。
5. ナビゲーションボタンOFF、アドレスバーONの状態で復元されることを確認する。

### TC-06: 既存のアドレスバー操作確認

1. アドレスバーを表示する。
2. URLを入力または貼り付ける。
3. Enterまたは移動ボタンでページを表示できることを確認する。
4. 現在URLをコピーできることを確認する。

### TC-07: ナビゲーションボタン操作確認

1. ナビゲーションボタンを表示する。
2. 戻るボタンが動作することを確認する。
3. 進むボタンが動作することを確認する。
4. 再読み込みボタンが動作することを確認する。
5. ホームボタンが動作することを確認する。

## 既存機能確認

- MainWindow が通常通り起動する。
- 表示メニューの他項目が動作する。
- ウィンドウサイズメニューが動作する。
- お気に入りボタンが動作する。
- 設定画面を開閉できる。
- ヘルプ画面、バージョン情報画面を開ける。
- チケット029/030/031のウィンドウサイズ関連仕様が壊れていない。

## 補足

今回の主目的は、アドレスバーとナビゲーションボタンを別々の表示単位として扱えるようにすることである。

ユーザーが求めている状態:

- ボタン非表示、アドレスバーのみ表示の場合は、アドレスバーを左寄せにする。
- ボタンだけ表示、アドレスバー非表示の場合は、ボタンを左寄せにする。
- どちらかを非表示にしても、空白が残らないようにする。
